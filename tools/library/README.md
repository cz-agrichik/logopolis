# Библиотека: конвертер книг

Страницы библиотеки лежат в `library/` (на сайте — `/library/`). Этот конвертер делает для них книги:
греческий текст → перевод каждого слова в контексте, словарные формы, грамматика, перевод предложений
и **обороты** (устойчивые выражения: *ρίχνω μια ματιά* — «взглянуть»). Попутно он собирает **словарь сайта**
для «Своего текста».

| Где | Что |
|---|---|
| `library/index.html` | Полка: список книг и «Свой текст». Ссылки — из Кипропедии («Библиотека: читать тексты») и экрана «Обучение». |
| `library/read.html` | Читалка: `?book=<id>` — книга, `?own` — свой текст. Поменяли `reader.js`, `reader.css`, `owntext.js` или `library.js` — поднимите `?v=` у них в `index.html` и `read.html` (сброс кеша браузера). |
| `library/reader.js`, `reader.css` | Читалка: карточка слова и оборота, колода «Запомнить», поля, экспорт в Anki / Quizlet / Brainscape / CSV. Оформление — как в игре: пергамент, Noto Serif, терракотовая шапка с меандром, золотые главные кнопки. |
| `library/owntext.js` | Свой текст: разбор прямо в браузере по словарю сайта (формы, без ударений, элизии, обороты по леммам) и хранилище «Моих текстов» (`OwnText.Store`). |
| `library/library.js` | Полка и открытие книги или своего текста. |
| `library/catalog.js`, `dict.js`, `books/<id>.js` | Каталог, словарь сайта, книги — **создаёт конвертер**, руками не править. Переводы строк — `\n` и на Windows (в git файл не меняется целиком). |
| `library/local/` | Личная полка: книги из `private/`. В `.gitignore`, видна только при запуске с диска. |
| `tools/library/bookconverter.py` | Конвертер. `convert.bat` — двойной щелчок: покажет книги и спросит, какую собрать (пусто — все); из командной строки — `convert.bat potter`. |
| `tools/library/texts/<id>/` | Публичные книги: `book.json` + главы `*.txt`. Попадают на сайт. |
| `tools/library/private/<id>/` | Личные книги (в `.gitignore`). На сайт не попадают. |
| `tools/library/config.json` | Ключ и переводчик (в `.gitignore`). Образец — `config.example.json`. |
| `tools/library/cache/` | Ответы модели (в `.gitignore`): повторная сборка ничего не запрашивает. |

## Что можно класть на сайт

В `texts/` — только то, что можно выкладывать: свой текст, общественное достояние, текст с разрешения автора.
Поле `"license"` в `book.json` обязательно: без него публичная книга не соберётся.
Книги под авторским правом кладите в `private/`: они читаются с диска так же, а на сайт попадает только то,
что они добавили в **словарь сайта** — словарные данные без текста.

**Словарь сайта** (`library/dict.js`) собирается из всех книг, публичных и личных:

- форма → лемма, часть речи, грамматика и как форму переводили в книгах;
- лемма → значение (рус. и англ.) и часть речи;
- обороты → леммы по порядку, словарная форма, перевод (2–5 слов, без имён).

Предложений, их переводов и порядка слов текста в словаре нет. Имена собственные в него не попадают.

## Быстрый старт

1. `pip install stanza` (греческая модель Stanza скачается при первом запуске).
2. Ключ Gemini: <https://aistudio.google.com/apikey> → «Create API key» (банковская карта не нужна).
3. Скопируй `config.example.json` в `config.json` и впиши ключ в `"api_key"`.
4. Положи книгу: папка `texts/<id>/` или `private/<id>/` (id — латиница, цифры, дефис), в ней главы `*.txt` и `book.json`:

```json
{
  "title": "Ένα ήσυχο πρωί",
  "author": "…",
  "level": "A2",
  "about": "о чём книга, одной строкой",
  "chapters": "*.txt",
  "license": "свой текст"
}
```

`chapters` — маска или список глав по порядку (`glava2` идёт раньше `glava10`), по умолчанию все `*.txt`.
Первая непустая строка главы — её название.

5. `python bookconverter.py <id>`. Проверить качество на пяти предложениях: `python bookconverter.py <id> --limit 5`.
6. Открой `library/index.html` двойным щелчком: книга уже на полке.

```
python bookconverter.py                    # какие книги есть и собраны ли
python bookconverter.py demo potter        # собрать книги
python bookconverter.py --all              # все
python bookconverter.py potter --offline   # только из кеша, ни одного запроса
python bookconverter.py potter --retry-bad # заново спросить куски, где модель давала негодный ответ
python bookconverter.py potter --no-phrases --no-levels
python bookconverter.py potter --html      # ещё и один самодостаточный файл out/potter.html — переслать, на телефон
python bookconverter.py --dict             # пересобрать каталоги и словарь сайта из готовых книг
python bookconverter.py --list-models
python bookconverter.py --candidates       # tools/words/library_candidates.tsv — кандидаты в колоды игры (A1–B1, которых нет в колодах)
python test_converter.py                   # проверка конвертера без Stanza и без модели (npm run test:library)
```

## Что делает языковая модель

1. **Перевод в контексте.** Пачки по ~80 слов: перевод предложений, значение каждого слова в этом предложении
   (έμεναν → «жили»), словарная форма (`το αγόρι`, `μένω`, `στο` → `σε + ο`).
2. **Словарные значения.** Каждая новая лемма один раз: значения (рус. и англ.) и часть речи.
   Политоника в ответах (*ἀλλάζω*, *ἀποκτῶ*) переводится в монотонику (`monotonic`). После всех глав словарные формы
   сверяются с уже известными словами — словами колод игры и ключами лемм книги (`settle_lemmas`, без таблиц):
   перевод в контексте иногда даёт словарной формой саму форму (*μπορούσα*, *είπε*) или обрывок (*λλάζω*), проход лемм
   исправляет (*μπορώ*, *λέω*, *αλλάζω*) — если исправленная форма известна, слова переходят к ней (одна лемма — один
   ключ). Если исправленная незнакома, а прежняя — слово из колод, в исправленной два ударения или она потеряла
   ударение (*μεγαλώνω* → «μεγαλώνον», *ποτέ* → «ποτε») — остаётся прежняя.
   Глаголы, у которых и после этого словарная форма — изменённая (*σκεφτόταν*, *έβαζε*, *φορώντας*: не кончается на
   -ω, -μαι, -ται, -ει), один раз переспрашиваются коротким запросом без текста книги (`fix_verb_heads`, кеш `verb1`),
   и слова переходят к исправленной лемме (*σκέφτομαι*, *βάζω*, *φοράω*).
3. **Обороты.** Отдельный проход пачками по ~160 слов: какие слова текста образуют устойчивое выражение,
   его словарная форма (глагол — в 1-м лице: *ρίχνω μια ματιά*) и перевод. У оборота свой кеш и своя версия
   промпта (`PHRASE_PROMPT_VERSION`): старые ответы перевода остаются в силе.
   Две главы «Поттера» — около 35 запросов.
   Ответы проверяются (`check_phrase`): отбрасываются обороты с опечаткой или выдумкой в словарной форме,
   с переводом не по-русски, со словами не из текста и из одних служебных слов; глагол, записанный формой из текста
   или с опечаткой в ударении, заменяется леммой (*παρίστανε πως* → *παριστάνω πως*); оборот без ударений («πολλες φορες») берёт их
   у слов текста (*πολλές φορές*). Лёгкая модель
   (`gemini-flash-lite`) иногда смешивает алфавиты («τίποта») — такие словарные формы не берутся ни в книгу, ни в словарь.
   Качество выше у `gemini-flash-latest` (поле `model` в `config.json`), но её дневной лимит меньше.
4. **Формы.** Каждая изменённая форма книги (не совпадающая с леммой: *ξύπνησαν* ← *ξυπνάω*) один раз уходит модели:
   грамматика по-русски («аорист, 3 л. мн. ч.», «род. п. мн. ч.», «неправильный аорист»), перевод именно этой формы
   («проснулись») и уровень формы (аорист неправильного глагола — позже правильного). Таблицей это не описать — потому
   модель. Пачки по 50, кеш по каждой форме (`form1`) и пачками (`form`), `FORM_PROMPT_VERSION`, `--no-forms`.
   В книге — `forms`: `"ξύπνησαν|ξυπνώ": ["аорист, 3 л. мн. ч.", "проснулись", "A2"]`; в словаре сайта — 5–7-й элементы формы.
   Уровень спрашивается только про грамматику (`FORM_PROMPT_VERSION` 2), но лёгкая модель всё равно поднимает формы
   редких слов (*έδειξε*, *χάλασε* — B1 при сотне аористов A2). Поэтому модель сверяется сама с собой
   (`calibrate_form_levels`): формы с одинаковыми признаками Stanza (часть речи + UD feats) — одна грамматика;
   B1 и выше опускается до уровня, который покрывает 80% таких форм книги (если их не меньше 8). C1+ (кафаревуса) не трогаем.
   Варианты одного глагола — одна лексема: ключ леммы на -ώ (`ξυπνάω` = `ξυπνώ`).
   Личной форме модель иногда даёт перевод инфинитивом — так переводят сослагательное после να («θέλει να αγοράσει» —
   «хочет купить»), но в карточке формы «αγοράσει — купить» — перевод леммы. Такие формы (в грамматике есть лицо,
   перевод — инфинитив: `personal_form`, `ru_infinitive`) переспрашиваются отдельно (`fix_form_infinitives`,
   `FORM_FIX_SYSTEM`): только они, коротко, с кешем `formfix1` / `formfix` и версией `FORM_FIX_VERSION` —
   «купит», «найдёшь», «оставим». Читалка такой перевод тоже не показывает как перевод формы.
5. **Уровни (CEFR).** После всех глав — уровень каждой леммы и оборота (`level`), пачками по 80, свой кеш
   (`LEVEL_PROMPT_VERSION`). Мнение — одно из четырёх: `"B1"` — определён; `"A2–B1"` — на границе двух соседних;
   `"?"` — модель не берётся судить (редкое, книжное, узкое, опечатка); поля нет — ответа нет (лимит, пропуск,
   ответ не по правилам: несоседние уровни, «C3»…). Греческие буквы в ответе (Β1, Γ1) понимаются как B1, C1.
   Слова и выражения из встроенных колод игры (`content/ru/words.js`, колоды `a1-*`, `a2-*`, `b1-*`) берут уровень
   колоды — по учебнику — и модели не отправляются. `--no-levels` — без этого прохода.
   В книге — `lemmas[key].level` и четвёртый элемент оборота; в словаре сайта — так же. Читалка показывает уровень
   значком рядом с частью речи, он же — в карточках и в экспорте (Anki, таблица).

Каждый ответ сохраняется в `cache/cache.json`. Негодный тоже: если модель на каком-то куске раз за разом
отвечает не-JSON (так было на одной пачке второй главы «Поттера»), кусок помечается в кеше (`_bad`), и следующие
запуски не тратят на него запросы — перевод сразу идёт по одному предложению (а те кешируются как обычно).
Сам негодный ответ дописывается в `cache/bad_replies.txt` — посмотреть, обо что модель спотыкается. Спросить такие
куски заново — `--retry-bad`. Разбор ответа терпимый: переводы строк внутри строк, лишняя запятая перед `]`, ответ, повторённый дважды (`{…}{…}`), и перепутанные скобки у пунктов списка оборотов (потерянная открывающая, лишняя или недостающая закрывающая, «висячие» номера) не мешают. В негодном ответе кеш хранит и сырой текст (`raw`): когда разбор станет терпимее, такой кусок разберётся без нового запроса.

**Отказ фильтра.** На известной книге модель иногда не отвечает вовсе (у Gemini — `PROHIBITED_CONTENT`/`RECITATION`), и повтор
не помогает: в 4-й главе «Поттера» так выпали три предложения и одна пачка оборотов. Такие запросы конвертер пишет в
`cache/blocked.json` (ключ кеша → что это, вид запроса, сам промпт). Ответ можно вписать в `cache/manual.json` — под тем же
ключом и в том же формате, что ждут от модели (`{"sentences": …, "words": …}` для перевода, `{"phrases": …}` для оборотов),
например попросив Claude: следующий запуск возьмёт его вместо кеша, а пропавший запрос исчезнет из `blocked.json`.
Оба файла — в `cache/`, то есть не в git: в них текст книги. Словарные значения и уровни кешируются ещё и **по одному слову**
(`lemma1`, `level1`: словарная форма + подсказка): пачки зависят от того, какие слова стоят до них, и раньше одно
изменившееся слово сдвигало все следующие пачки — их приходилось спрашивать заново. Теперь к модели уходят только
действительно новые слова, а заголовок каждого прохода честно пишет, сколько возьмётся из кеша и сколько уйдёт к модели. Если провайдер сказал «на сегодня всё», конвертер запишет готовое
(в читалке будет пометка «перевод неполный»). Запусти его снова завтра или с другим переводчиком — он продолжит
с того же места. **Автодозвон:** модель перегружена (HTTP 503 «high demand»), сбой сервера (5xx) или пропала связь —
конвертер ждёт и повторяет тот же запрос с растущей паузой (10, 20, 40, 80 с, дальше по 2 минуты), пишет время каждой
попытки. Сдаётся, только если на один запрос ушло `busy_wait` минут (по умолчанию 30, в `config.json`): тогда, как при
лимите, дособирает книгу из кеша, а следующий запуск продолжит. Ctrl+C ничего не ломает. Правишь промпт — увеличь его версию (`PROMPT_VERSION`,
`LEMMA_PROMPT_VERSION`, `PHRASE_PROMPT_VERSION`), чтобы новые ответы не смешались со старыми.

## Читалка

- **Слово** — три слоя: сверху форма и её перевод в этом предложении (*ξύπνησαν* — «проснулись»), ниже грамматика формы и
  её уровень, ниже лемма со словарным значением и уровнем слова («от *ξυπνάω* — просыпаться»). Форма — только с переводом
  формы, лемма — только со словарным: если модель дала личной форме глагола перевод в инфинитиве, он не показывается
  («перевод этой формы неизвестен»), берётся перевод из прохода форм. На полях — «ξύπνησαν — проснулись» и мелко
  «аорист от ξυπνάω»; у оборота — словарная форма со словарным переводом. В карточке и в Anki — слово крупно, встреченная
  форма мелко, на обороте — её перевод и грамматика; в таблице — столбцы `form_grammar`, `form_translation`, `form_level`.
- **Оборот** — слова под тонким пунктиром. Лексическая единица тогда — весь оборот: при нажатии он подсвечивается, его перевод —
  сверху карточки (крупно), само слово — ниже. «Запомнить оборот» — карточка оборота (ключ `phrase:<словарная форма>`,
  часть речи «оборот»): подсвечиваются все его вхождения, на полях он подписывается целиком (и запомненное слово
  внутри оборота — тоже оборотом). Только слово — ссылкой «или только слово…».
- **Запомнить** — слово (лемма) в колоду читалки; все его формы подсвечиваются во всех книгах, на полях — перевод.
  «Выучил» убирает подсветку. Колода — в `localStorage` браузера (`greek-reader:deck:v2`): у сайта и у файлов с диска
  она своя. Поэтому время от времени делай «Сохранить резервную копию» — и «Загрузить» её в другом месте.
- **Экспорт** — Anki (`.txt`, колода «Греческий из книг»), Quizlet (текст в буфер), Brainscape (`.csv`), таблица (`.csv`).
- **Карточка формы** — «или эту форму…» (ключ `form:<форма>|<лемма>`): *βρίσκεται* и *θα βρω* учатся по-разному. Уровень —
  наибольший из уровня слова и уровня формы.
- **Мой уровень и кандидаты** — в панели карточек: «Мой уровень» (`greek-reader:my-level`; по умолчанию — самый высокий
  из включённых уровней колод игры) и фильтр «моего уровня · выше · все». Карточки — кандидаты: своего уровня и ниже — учить.
- **С игрой** (общее хранилище браузера): читалка читает обучение игры (`greekgame.learn.v1`) — выученные в игре слова на
  полях зелёные, в карточке «✓ выучено в игре»; игра читает карточки читалки (`greek-reader:deck:v2`, ещё учатся, уровень
  не выше «моего») и держит из них колоду **«📖 Слова из чтения»** (`Decks.setReadingDeck`, `Reading.sync` в `ui/desktop/school.js`):
  прогресс у слова общий для всех колод игры (`Decks.wordKey`): выучили в A1 — выучено и тут, и наоборот; в раунд слово
  попадает один раз. У каждого ключа хранилища один писатель.
- **Уровень текста** — по покрытию (`OwnText.textLevel`, в конвертере `text_level` → `estimate` в каталоге): самый низкий
  уровень, при котором знакомы 95% слов (98% — свободно); слово в тексте — max(уровень слова, уровень формы).
- **Мои тексты** — вставить или открыть `.txt`; слова и обороты ищутся в словаре сайта, незнакомые подчёркнуты,
  у них в карточке ссылка на Викисловарь. Тексты сохраняются только в браузере посетителя (`localStorage`,
  `greek-reader:own-texts:v1`; прежний одиночный `greek-reader:own-text` переносится сам): полка «Мои тексты» на
  `library/index.html`, `read.html?own=<id>` — открыть, `&edit` — править. «Скачать копию всех текстов» (JSON) и
  «Загрузить из файла» (`.json` — копия: новые добавляются, более свежие обновляют; `.txt` — новый текст).

## Формат книги (`library/books/<id>.js`, версия 3)

```javascript
window.GREEK_BOOK_DATA = {
  "version": 3,
  "title": "…",
  "text": "…весь текст, главы через пустые строки…",
  "chapters": [{"title": "…", "start": 0, "end": 16326}],
  "sentences": [[start, end, "перевод предложения"], …],
  "lemmas": {"αγόρι": {"head": "το αγόρι", "ru": "мальчик", "en": "boy", "pos": "сущ., ср. р.", "level": "A1"}},
  "words": [{"start": 80, "end": 85, "s": 4, "lemma": "το αγόρι", "key": "αγόρι", "upos": "NOUN", "feats": "…", "ru": "мальчик"}],
  "phrases": [[[12, 13, 15], "ρίχνω μια ματιά", "взглянуть", "A2–B1"]],
  "forms": {"ξύπνησαν|ξυπνώ": ["аорист, 3 л. мн. ч.", "проснулись", "A2"]},
  "meta": {"provider": "gemini", "model": "…", "created": "…", "complete": true, "phrases": true, "levels": true}
};
```

`start` и `end` — позиции в символах Unicode, конец не включается; `s` — номер предложения; `key` — лемма без
артикля в нижнем регистре (по нему работают карточки и словарь); в `phrases` — номера слов из `words`.
Читалка понимает и версии 1–2 (без оборотов).
