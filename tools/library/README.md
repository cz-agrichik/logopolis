# Библиотека: конвертер книг

Страницы библиотеки лежат в `library/` (на сайте — `/library/`). Этот конвертер делает для них книги:
греческий текст → перевод каждого слова в контексте, словарные формы, грамматика, перевод предложений
и **обороты** (устойчивые выражения: *ρίχνω μια ματιά* — «взглянуть»). Попутно он собирает **словарь сайта**
для «Своего текста».

| Где | Что |
|---|---|
| `library/index.html` | Полка: список книг и «Свой текст». Ссылки — из Кипропедии («Библиотека: читать тексты») и экрана «Обучение». |
| `library/read.html` | Читалка: `?book=<id>` — книга, `?own` — свой текст. Поменяли `reader.js`, `reader.css`, `owntext.js` или `library.js` — поднимите `?v=` у них в `index.html` и `read.html` (сброс кеша браузера). |
| `library/reader.js`, `reader.css` | Читалка: карточка слова и оборота, колода «Запомнить», поля, экспорт в Anki / Quizlet / Brainscape / CSV. Оформление — как в игре: пергамент, Noto Serif, терракотовая шапка с меандром, золотые главные кнопки. |
| `library/owntext.js` | Свой текст: разбор прямо в браузере по словарю сайта (формы, без ударений, элизии, обороты по леммам) и хранилище «Моих текстов» (`OwnText.Store`). |
| `library/library.js` | Полка и открытие книги или своего текста. |
| `library/catalog.js`, `dict.js`, `books/<id>.js` | Каталог, словарь сайта, книги — **создаёт конвертер**, руками не править. |
| `library/local/` | Личная полка: книги из `private/`. В `.gitignore`, видна только при запуске с диска. |
| `tools/library/bookconverter.py` | Конвертер. `convert.bat` — двойной щелчок: покажет книги и спросит, какую собрать (пусто — все); из командной строки — `convert.bat potter`. |
| `tools/library/texts/<id>/` | Публичные книги: `book.json` + главы `*.txt`. Попадают на сайт. |
| `tools/library/private/<id>/` | Личные книги (в `.gitignore`). На сайт не попадают. |
| `tools/library/config.json` | Ключ и переводчик (в `.gitignore`). Образец — `config.example.json`. |
| `tools/library/cache/` | Ответы модели (в `.gitignore`): повторная сборка ничего не запрашивает. |

## Что можно класть на сайт

В `texts/` — только то, что можно выкладывать: свой текст, общественное достояние, текст с разрешения автора.
Поле `"license"` в `book.json` обязательно: без него публичная книга не соберётся.
Книги под авторским правом кладите в `private/`: они читаются с диска так же, а на сайт попадает только то,
что они добавили в **словарь сайта** — словарные данные без текста.

**Словарь сайта** (`library/dict.js`) собирается из всех книг, публичных и личных:

- форма → лемма, часть речи, грамматика и как форму переводили в книгах;
- лемма → значение (рус. и англ.) и часть речи;
- обороты → леммы по порядку, словарная форма, перевод (2–5 слов, без имён).

Предложений, их переводов и порядка слов текста в словаре нет. Имена собственные в него не попадают.

## Быстрый старт

1. `pip install stanza` (греческая модель Stanza скачается при первом запуске).
2. Ключ Gemini: <https://aistudio.google.com/apikey> → «Create API key» (банковская карта не нужна).
3. Скопируй `config.example.json` в `config.json` и впиши ключ в `"api_key"`.
4. Положи книгу: папка `texts/<id>/` или `private/<id>/` (id — латиница, цифры, дефис), в ней главы `*.txt` и `book.json`:

```json
{
  "title": "Ένα ήσυχο πρωί",
  "author": "…",
  "level": "A2",
  "about": "о чём книга, одной строкой",
  "chapters": "*.txt",
  "license": "свой текст"
}
```

`chapters` — маска или список глав по порядку (`glava2` идёт раньше `glava10`), по умолчанию все `*.txt`.
Первая непустая строка главы — её название.

5. `python bookconverter.py <id>`. Проверить качество на пяти предложениях: `python bookconverter.py <id> --limit 5`.
6. Открой `library/index.html` двойным щелчком: книга уже на полке.

```
python bookconverter.py                    # какие книги есть и собраны ли
python bookconverter.py demo potter        # собрать книги
python bookconverter.py --all              # все
python bookconverter.py potter --offline   # только из кеша, ни одного запроса
python bookconverter.py potter --no-phrases
python bookconverter.py potter --html      # ещё и один самодостаточный файл out/potter.html — переслать, на телефон
python bookconverter.py --dict             # пересобрать каталоги и словарь сайта из готовых книг
python bookconverter.py --list-models
python test_converter.py                   # проверка конвертера без Stanza и без модели (npm run test:library)
```

## Что делает языковая модель

1. **Перевод в контексте.** Пачки по ~80 слов: перевод предложений, значение каждого слова в этом предложении
   (έμεναν → «жили»), словарная форма (`το αγόρι`, `μένω`, `στο` → `σε + ο`).
2. **Словарные значения.** Каждая новая лемма один раз: значения (рус. и англ.) и часть речи.
3. **Обороты.** Отдельный проход пачками по ~160 слов: какие слова текста образуют устойчивое выражение,
   его словарная форма (глагол — в 1-м лице: *ρίχνω μια ματιά*) и перевод. У оборота свой кеш и своя версия
   промпта (`PHRASE_PROMPT_VERSION`): старые ответы перевода остаются в силе.
   Две главы «Поттера» — около 35 запросов.
   Ответы проверяются (`check_phrase`): отбрасываются обороты с опечаткой или выдумкой в словарной форме,
   с переводом не по-русски, со словами не из текста и из одних служебных слов; глагол, записанный формой из текста
   или с опечаткой в ударении, заменяется леммой (*παρίστανε πως* → *παριστάνω πως*). Лёгкая модель
   (`gemini-flash-lite`) иногда смешивает алфавиты («τίποта») — такие словарные формы не берутся ни в книгу, ни в словарь.
   Качество выше у `gemini-flash-latest` (поле `model` в `config.json`), но её дневной лимит меньше.

Каждый ответ сохраняется в `cache/cache.json`. Если провайдер сказал «на сегодня всё», конвертер запишет готовое
(в читалке будет пометка «перевод неполный»). Запусти его снова завтра или с другим переводчиком — он продолжит
с того же места. Ctrl+C ничего не ломает. Правишь промпт — увеличь его версию (`PROMPT_VERSION`,
`LEMMA_PROMPT_VERSION`, `PHRASE_PROMPT_VERSION`), чтобы новые ответы не смешались со старыми.

## Переводчики

| translator | Модель по умолчанию | Бесплатно (осень 2026) | Ключ |
|---|---|---|---|
| `gemini` | `gemini-flash-lite-latest` | около 500 запросов в день | aistudio.google.com/apikey |
| `groq` | `openai/gpt-oss-120b` | 1 000 запросов и ~200 тыс. токенов в день | console.groq.com/keys |
| `openrouter` | `openrouter/free` | 50 запросов в день | openrouter.ai/keys |
| `ollama` | `gemma3:12b` | без лимитов, офлайн | не нужен |
| `custom` | — | любой OpenAI-совместимый API (`base_url`, `model`) | по ситуации |
| `argos` | — | офлайн, качество слабое, без оборотов | не нужен |
| `none` | — | только грамматика | не нужен |

Ключ можно держать и в переменной окружения: `GEMINI_API_KEY`, `GROQ_API_KEY`, `OPENROUTER_API_KEY`.
Бесплатный Gemini может использовать присланные тексты для обучения моделей — учитывай это для личных текстов.

## Читалка

- **Слово** — перевод в этом предложении, словарная форма, значение, часть речи, грамматика, «Перевод предложения».
- **Оборот** — слова под тонким пунктиром. Лексическая единица тогда — весь оборот: при нажатии он подсвечивается, его перевод —
  сверху карточки (крупно), само слово — ниже. «Запомнить оборот» — карточка оборота (ключ `phrase:<словарная форма>`,
  часть речи «оборот»): подсвечиваются все его вхождения, на полях он подписывается целиком (и запомненное слово
  внутри оборота — тоже оборотом). Только слово — ссылкой «или только слово…».
- **Запомнить** — слово (лемма) в колоду читалки; все его формы подсвечиваются во всех книгах, на полях — перевод.
  «Выучил» убирает подсветку. Колода — в `localStorage` браузера (`greek-reader:deck:v2`): у сайта и у файлов с диска
  она своя. Поэтому время от времени делай «Сохранить резервную копию» — и «Загрузить» её в другом месте.
- **Экспорт** — Anki (`.txt`, колода «Греческий из книг»), Quizlet (текст в буфер), Brainscape (`.csv`), таблица (`.csv`).
- **Мои тексты** — вставить или открыть `.txt`; слова и обороты ищутся в словаре сайта, незнакомые подчёркнуты,
  у них в карточке ссылка на Викисловарь. Тексты сохраняются только в браузере посетителя (`localStorage`,
  `greek-reader:own-texts:v1`; прежний одиночный `greek-reader:own-text` переносится сам): полка «Мои тексты» на
  `library/index.html`, `read.html?own=<id>` — открыть, `&edit` — править. «Скачать копию всех текстов» (JSON) и
  «Загрузить из файла» (`.json` — копия: новые добавляются, более свежие обновляют; `.txt` — новый текст).

## Формат книги (`library/books/<id>.js`, версия 3)

```javascript
window.GREEK_BOOK_DATA = {
  "version": 3,
  "title": "…",
  "text": "…весь текст, главы через пустые строки…",
  "chapters": [{"title": "…", "start": 0, "end": 16326}],
  "sentences": [[start, end, "перевод предложения"], …],
  "lemmas": {"αγόρι": {"head": "το αγόρι", "ru": "мальчик", "en": "boy", "pos": "сущ., ср. р."}},
  "words": [{"start": 80, "end": 85, "s": 4, "lemma": "το αγόρι", "key": "αγόρι", "upos": "NOUN", "feats": "…", "ru": "мальчик"}],
  "phrases": [[[12, 13, 15], "ρίχνω μια ματιά", "взглянуть"]],
  "meta": {"provider": "gemini", "model": "…", "created": "…", "complete": true, "phrases": true}
};
```

`start` и `end` — позиции в символах Unicode, конец не включается; `s` — номер предложения; `key` — лемма без
артикля в нижнем регистре (по нему работают карточки и словарь); в `phrases` — номера слов из `words`.
Читалка понимает и версии 1–2 (без оборотов).
