# Инструменты

Скрипты для работы над игрой — не часть игры (в `index.html` не подключаются). Запускаются из корня проекта.
Для тех, что открывают страницу в браузере, нужен Playwright: `npm i` (он же нужен «золотому эталону» в `tests/`).

| Скрипт | Что делает |
|---|---|
| `npm run audit:pedia` (`tools/pedia/audit.js`) | Кипропедия против ядра во всех открытых эпохах: каждая статья открывается без ошибок (не подменяется «Как играть»), таблицы уровней, цены обрядов и знаний, вместимость. Код выхода 1, если что-то разошлось. **Запускать после любой правки чисел или справки.** |
| `node tools/pedia/dump.js <эпоха> <файл> [all]` | Все статьи справки текстом — прочитать подряд или сравнить до и после правки (`diff`). `all` — знания этой эпохи тоже изучены. |
| `npm run prices` (`tools/balance/prices.js`) | Сверка цен эпох по ценнику труда (`BALANCE.worth`): знания «с умом» и «через силу», чудеса, переход и во сколько раз каждая эпоха дороже прошлой. Ориентиры — в README, «Принципы». |
| `node tools/art/sheet.js <файл.png> [ключи]` | Лист рисунков `Art` крупно, с подписями (без ключей — все здания). |
| `node tools/art/looks.js <файл.png> [типы]` | Облики зданий по эпохам и уровням, как на карте, с названием облика (`Looks.looks`). |
| `python3 tools/words/pools.py <данные> [папка]` | Пулы кандидатов в колоды из выгрузок учебника «Κλικ στα ελληνικά» (`output.csv` и списки частотности): чего ещё нет в игре, по уровням (правило уровня — гибридное) и частям речи, частые — первыми. |
| `python3 tools/words/apply_decks.py <добавления.py> [--write]` | Вносит отобранные слова в `content/ru/words.js`: проверяет повторы слов и переводов, предупреждает о пересечениях смысла; с `--write` записывает и поднимает `WORD_DECKS_VERSION`. |

## Как пополнить колоды

1. `python3 tools/words/pools.py <папка с выгрузками> pools` — пулы `pools/A1_neut.txt`, `pools/B1_adj.txt`…
2. Отобрать слова вручную в новый файл по образцу `tools/words/additions_v4.py` (версия 4 — +100 слов в A1, A2, B1; уже внесена):
   свой перевод (английский столбец выгрузки — машинный, только ориентир), подсказка по правилам README
   («Встроенные колоды и уровни»), в колоде 16–45 слов; большие колоды делить (`SPLIT`).
3. `python3 tools/words/apply_decks.py <файл>` — исправить ошибки и, по возможности, заметки о пересечении смысла;
   затем `--write`, `npm test`, поднять `ASSET_V` в `index.html`, поправить README (счётчики слов).
   Прогресс игроков сохранится: он идёт за греческим словом, даже если колоду поделили или убрали.
