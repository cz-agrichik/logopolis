# Инструменты

Скрипты для работы над игрой — не часть игры (в `index.html` не подключаются). Запускаются из корня проекта.
Для тех, что открывают страницу в браузере, нужен Playwright: `npm i` (он же нужен «золотому эталону» в `tests/`).

| Скрипт | Что делает |
|---|---|
| `npm run audit:pedia` (`tools/pedia/audit.js`) | Кипропедия против ядра во всех открытых эпохах: каждая статья открывается без ошибок (не подменяется «Как играть»), таблицы уровней, цены обрядов и знаний, вместимость. Код выхода 1, если что-то разошлось. **Запускать после любой правки чисел или справки.** |
| `node tools/pedia/dump.js <эпоха> <файл> [all]` | Все статьи справки текстом — прочитать подряд или сравнить до и после правки (`diff`). `all` — знания этой эпохи тоже изучены. |
| **`tools/balance/balancer.html`** — открыть с диска | **Балансер** по эпохам (начало и конец каждой): 1) здания и бонусы, 2) население и склады, 3) множитель λ, 4) курсы ресурсов в зерне, 5) выпуск, 6) наука, 7) обязательное в λ, 8) постройки и улучшения, 9) курс «λ ↔ ресурсы», 10) итог эпохи «с умом» и «ресурсами», 11) окупаемость чудес, 12) Римский Кипр в разработке — договорённые числа и идеи со статусами (`tools/balance/rome.js`). Считает движком игры в браузере; сколько зданий — правится в разделе 1. `npm run balance` — та же сводка в консоли. |
| `npm run prices` (`tools/balance/prices.js`) | Сверка цен эпох по ценнику труда (`BALANCE.worth`): знания «с умом» и «через силу», чудеса, переход и во сколько раз каждая эпоха дороже прошлой. Ориентиры — в README, «Принципы». |
| `npm run phone` (`tools/phone/check.js <папка> [устройство \| ШxВ] [эпоха]`) | Телефон в альбомной ориентации: снимки всех экранов (заслонка, карта, вкладки, окна, справка, учёба, раунд) и проверка касаний — подсказка долгим нажатием, ⏫, «Строить» касанием и 🔁, крестики, ☰. Код выхода 1, если что-то не так. Устройства — из Playwright (`"iPhone SE landscape"`) или размер (`740x340`). **Запускать после правок интерфейса.** |
| `node tools/art/gallery.js [файл.html]` | **Галерея всех рисунков** → `tools/art/gallery.html` (открывается с диска): каждый рисунок крупно, название, на каких уровнях и в какой эпохе он стоит на карте, и пара предложений «что хотел сказать автор» из `tools/art/notes.js`. Перерисовали или добавили рисунок — допишите строчку в `notes.js` и пересоберите; рисунки без описания перечислятся. |
| `node tools/art/sheet.js <файл.png> [ключи]` | Лист рисунков `Art` крупно, с подписями (без ключей — все здания). |
| `node tools/art/looks.js <файл.png> [типы]` | Облики зданий по эпохам и уровням, как на карте, с названием облика (`Looks.looks`). |
| `node tools/balance/hellenic-techs.js '<buy JSON>'` | «Что если» для знаний эллинского Кипра: закупка за рубежом (`buy` на каждый λ прежней цены — монеты, папирус…), λ «с умом» по курсу обрядов и сколько это от цели пути «ресурсами» (`TARGET`). Игру не меняет. |
| `python3 tools/words/pools.py <данные> [папка]` | Пулы кандидатов в колоды из выгрузок учебника «Κλικ στα ελληνικά» (`output.csv` и списки частотности): чего ещё нет в игре, по уровням (правило уровня — гибридное) и частям речи, частые — первыми. |
| `python3 tools/words/apply_decks.py <добавления.py> [--write]` | Вносит отобранные слова в `content/ru/words.js`: проверяет повторы слов и переводов, предупреждает о пересечениях смысла; с `--write` записывает и поднимает `WORD_DECKS_VERSION`. |

## Как пополнить колоды

**Сначала — `tools/words/LEVELS.md`**: правила уровней. Главное: «есть в учебнике A1» ≠ A1 — каждое слово A1 проходит тест
взрослого новичка из трёх вопросов; сомневаешься — A2.

1. `python3 tools/words/pools.py <папка с выгрузками> pools` — пулы `pools/A1_neut.txt`, `pools/B1_adj.txt`…
2. Отобрать слова вручную в новый файл по образцу `tools/words/additions_v4.py`, `additions_v5.py` или `additions_v6.py` (версии 4–6 —
   по +100 слов в A1, A2, B1; уже внесены; в v5 — ещё перенос слов между колодами и уровнями `MOVE`, правка перевода `EDIT`, порядок `ORDER`;
   в v6 — тематические колоды `NEW`, куда `MOVE` переносит слова своей темы):
   свой перевод (английский столбец выгрузки — машинный, только ориентир), подсказка по правилам README
   («Встроенные колоды и уровни»), в колоде 15–70 слов (так проверяет тест); большие колоды делить (`SPLIT`).
   Ещё источник — слова книг библиотеки: `python tools/library/bookconverter.py --candidates` → `tools/words/library_candidates.tsv`
   (точный уровень A1/A2/B1 по мнению модели). Для версии 8 разобраны все леммы словаря сайта, которых нет в колодах, с уровнем
   учебника и частотностью рядом (`additions_v8.py` — что взято, что отсеяно и почему); уровень и перевод модели — только ориентир.
   A1 пересобирается целиком операцией `LAYOUT` (`additions_v10.py`); чистка уровня — `MOVE` (`additions_v12.py`).
3. `python3 tools/words/apply_decks.py <файл>` — исправить ошибки и, по возможности, заметки о пересечении смысла;
   затем `--write`, `npm test`, поднять `ASSET_V` в `index.html`, поправить README (счётчики слов).
   Прогресс игроков сохранится: он идёт за греческим словом, даже если колоду поделили или убрали.
