# Λόγος · Кипр сквозь эпохи

Градостроительный симулятор по истории Кипра, совмещённый с изучением греческого.
Город растёт сам, но всё важное (знания, чудеса, высокие уровни зданий, переход эпох) требует **λ Логоса**,
а Логос даётся **только за верные ответы на карточки**. Играть можно и без карточек, но с ними заметно быстрее.

Сейчас в игре три эпохи — Медно-каменный век (энеолит), Бронзовый век (Аласия) и железный век «Царства-города» — и четвёртая,
«Эллинский Кипр», целиком; переход из неё ведёт в «Римский Кипр» — он описан на треть (пять знаний и римский храм Афродиты), перехода дальше пока нет.
Встроено ~1350 карточек из учебника «Κλικ στα ελληνικά» с русским переводом: A1 (~590 слов, включены сразу),
A2 (~400) и B1 (~360) — выключены, пока игрок их не включит.

Этот файл — главный справочник по проекту: где что лежит, как устроены механики, какие решения уже приняты
и почему, как вносить изменения. Правила для игрока — в самой игре, в **Кипропедии** (кнопка «?» в шапке, F1).

## 1. Запуск

- Открыть `index.html` в Chrome/Edge прямо с диска (`file://`). Сборки, сервера и зависимостей нет.
- `index.html?dev` — отладочные кнопки во вкладке «Эпоха»: +500 λ, +1000 ресурсов, коза, набег.
- `index.html?reset` — аварийный сброс сохранения.
- Скрипты и стили подключаются с `?v=ASSET_V`. **После любого изменения кода поднимайте одно число — `ASSET_V`
  в начале `index.html`**, иначе браузер возьмёт старые файлы из кэша. Список скриптов и их порядок — массив `ASSETS`
  в конце `index.html` (скрипты дописываются через `document.write`, синхронно и по порядку, как обычные теги);
  новый файл добавляется туда одной строкой. Тест `boundary.test.js` проверяет, что каждый `.js` из слоёв есть в списке
  и что номеров версий в странице больше нет. `tests/load-core.js` берёт список ядра оттуда же.
- Опубликовано: **https://grecheskiy.com** — GitHub Pages из этого репозитория (файл `CNAME`), DNS в Cloudflare
  (CNAME `@` и `www` → `cz-agrichik.github.io`, «DNS only»). После пуша сайт обновляется за минуту-две, `index.html` кэшируется до 10 минут.
- Яндекс Метрика (счётчик 114153547, вебвизор) — в `<head>` `index.html`; включается только по `https:`, поэтому запуск с диска и тесты в статистику не попадают.

## 2. Архитектура

Код разложен по слоям так, чтобы у игры могло быть **несколько независимых интерфейсов** (ПК, планшет, телефон,
A/B-варианты одного экрана) с общими правилами и общими текстами.

```
core/        ЯДРО — правила игры и обучения. Без страницы, без хранилища браузера, без текстов.
content/ru/  ТЕКСТЫ на русском: названия, описания, истории, сообщения, Кипропедия, встроенные слова.
assets/      РИСУНКИ (SVG).
platform/    ПЛАТФОРМА: хранилище, перезапуск страницы, озвучка — для браузера.
ui/common/   ОБЩЕЕ ДЛЯ HTML-ИНТЕРФЕЙСОВ: каталог (числа + тексты), облики зданий, мелкие хелперы.
ui/desktop/  ИНТЕРФЕЙС ДЛЯ ПК: шапка, карта, вкладки, раунд карточек, «Обучение», Кипропедия, стили, запуск.
tests/       ТЕСТЫ: ядро без браузера, границы слоёв, «золотой эталон» в браузере.
tools/       ИНСТРУМЕНТЫ (не часть игры): проверка Кипропедии, сверка цен эпох, листы рисунков, пополнение колод — tools/README.md.
```

**Правило зависимостей:** `core` ни от кого не зависит (кроме встроенных колод из `content/ru/words.js` — это данные).
`content` и `ui/common` читают `core`. Интерфейс (`ui/desktop`) читает всё. Ядро никогда не зовёт интерфейс —
оно сообщает о событиях через `Bus` и возвращает **коды**, а не фразы. Это проверяет `tests/boundary.test.js`.

### Как ядро говорит с интерфейсом

- **Команды** — методы ядра: `Game.build(type, x, y)`, `Game.upgrade(b)`, `Game.perform(id)`, `Lesson.answer(...)`…
- **Статусы и причины** — объекты с кодами: `buildStatus()` → `{ ok: false, reason: { code: 'lack', items: [['wood', 12]] } }`.
  Текст — `Msg.reason(reason)`.
- **Летопись** — записи `{ t, k: 'built', p: { type, epoch } }`; текст — `Msg.log(entry)`.
- **События** — `Bus.on('log' | 'raid', fn)`: например, набег показывает всплывашку.
- **Сводки** — `Game.labor()`, `Game.buffedRes()`, `Decks.roundPreview()`, `Decks.totals()`: интерфейсу не нужно знать правила.
- **Обучение** живёт отдельно (`Learn.state`): все функции `Decks`/`Lesson` принимают его параметром.
  Награда в λ считается в обучении, а начисляется в городе: `Lesson.answer(Learn.state, …, Game.logosMult())` → `Game.addLogos(gain)`.

### Как добавить ещё один интерфейс (телефон, планшет, A/B-вариант)

1. Новая страница, например `mobile.html`: подключить `core/*`, `content/ru/*`, `assets/art.js`, `platform/browser.js`, `ui/common/*`
   в том же порядке, что и в `index.html`, а затем свои скрипты из `ui/mobile/`.
2. Свой запуск по образцу `ui/desktop/main.js`: `Game.genMap()`, `Session.start(BrowserIO)`, игровой цикл, `Session.saveAll()`.
3. Рисовать из `Cat`, `Looks`, `Msg`, `PediaBook`; правила не дублировать — только звать ядро.
4. Сохранения общие: все интерфейсы в одном браузере видят один и тот же город и одно обучение.
5. A/B-вариант того же экрана — так же отдельной страницей (или выбором набора скриптов в `index.html` по параметру);
   ядро и тексты не меняются.

Подписи кнопок и короткие фразы конкретного экрана живут рядом с его разметкой (в `ui/<интерфейс>/`);
всё, что нужно нескольким интерфейсам (названия, описания, сообщения, справка), — в `content/ru/`.

### Где менять, если нужно…

- **число баланса** — `BALANCE` или конкретное здание/знание/обряд в `core/defs.js`;
- **название, описание, историю** — `content/ru/lexicon.js`;
- **текст сообщения** (причина «нельзя», запись летописи) — `content/ru/messages.js`;
- **новое здание** — числа в `core/defs.js`, тексты в `lexicon.js`, рисунки `<префикс>0, 1, 2…` в `assets/art.js` по схеме обликов (раздел «Графика»; проверить — `tools/art/looks.js`),
  префикс в `Looks.ART` (`ui/common/looks.js`), при желании совет в `TIPS` (`content/ru/pedia.js`);
- **новое знание** — `TECHS` (+ тексты и `paths` в `lexicon.js`, медальон `t_<id>` в `art.js`, история в `TECH_STORY`);
- **новый обряд** — `RITUALS` (+ тексты, медальон `r_<id>`);
- **награды за задания** — `TASK_REWARDS`, `EARLY_FACTOR` в `core/learning/lesson.js`;
- **темп обучения по умолчанию** — `DEFAULT_SETTINGS`, `APPETITES`, `LEARN_DELAY` в `core/learning/srs.js`;
- **встроенные слова** — `content/ru/words.js`; если меняется перевод или слово переезжает в другую встроенную колоду —
  поднять `WORD_DECKS_VERSION` (прогресс переносится по греческому слову, в том числе между колодами);
- **статья справки** — `PEDIA_ARTICLES` в `content/ru/pedia.js` (`part: 'study'` — в части «Учёба»; статьи игры — ещё и в свою группу
  оглавления `PediaBook.GAME_GROUPS`: Основы → Город → Развитие → События; источники к статье — `SOURCES`); расчёт для неё —
  в `core/city/facts.js` (числа и id), текст — в `pedia.js`. Числа в текстах берите из данных (`${BALANCE…}`, `Game.…`),
  а не пишите руками — иначе они разойдутся с игрой;
- **новый файл** — одной строкой в `ASSETS` (`index.html`), на своё место по слоям.

После изменения механики **всегда обновляйте Кипропедию** — она должна описывать текущие правила —
и запускайте `npm run audit:pedia` (справка против ядра во всех эпохах) и, если менялись цены, `npm run prices`.

## 3. Состояние и сохранение

- Два мира — два сохранения в `localStorage`:
  - город — `Game.state`, ключ `greekgame.city.v1`: `epoch, res, logos, logosEarned, pop, techs, techPath, buildings, nextId, buffs, cooldowns, stash, timers, stats.{goats, gathered, rites}, tutorial, log, finished`;
  - обучение — `Learn.state`, ключ `greekgame.learn.v1`: `decks, progress, settings, learnLog, stats.{right, wrong, rounds, learned}, spread`.
- Сохраняется раз в 5 секунд, при уходе со страницы и после важных действий (`Session.saveAll()`).
- **Вторая вкладка.** Рядом с каждым сохранением лежит штамп `<ключ>.stamp` — какая вкладка писала последней. Вкладка пишет, только пока штамп её; если поверх записала другая (ушла вперёд, начала новую игру, стёрла всё), эта останавливается и больше ничего не сохраняет — окно «Игра открыта в другой вкладке» с кнопкой «Загрузить свежую игру». Проверка — при каждой записи, при возвращении на вкладку и по событию `storage`. Раньше забытая старая вкладка при закрытии браузера или возвращении на неё записывала свою игру поверх новой.
- Старое общее сохранение (`greekgame.save.v2`) при первом запуске делится на два, а оригинал остаётся копией `greekgame.save.v2.bak`.
- Прогресс — **у слова, а не у карточки** (с `v: 2` сохранения обучения): `progress[Decks.pkey(card)]`, ключ — `Decks.wordKey(front)`
  (строчные, без артикля, -άω → -ώ; ударение различает: πότε ≠ ποτέ). Одно слово в нескольких колодах — один прогресс,
  в раунд (`activeCards`) — один раз, карточкой первой колоды; сводки по группам и подборкам считают слова (`wordStats`).
  Сохранения v1 (`progress[cardId]`) переводятся один раз (`progressByWord`: дубли — самый продвинутый прогресс, ответы складываются).
  Удаление своей колоды (`removeDeck`) оставляет прогресс слов, которые есть в других колодах.
  Поля прогресса: `step` (шаги заучивания), `rev` (−1 — учится, ≥0 — индекс интервала выученного),
  `due` (когда снова пора), `last` (последний ответ), `right/wrong`, `built` (слово уже набирали), `back` (куда вернуться после забывания).
- **Три сброса** (решение: обучение ценнее города и не должно пропадать случайно):
  - «Новая игра» (`Game.newGame`) — город с нуля; обучение лежит отдельно и не трогается;
  - «Сбросить обучение» (`Decks.resetLearning`) — слова снова новые, город не трогается;
  - «Стереть всё» (`Session.wipe`) — как при первом запуске.
- Флаги `Game.resetting` / `Learn.resetting` не дают пересохранить старое во время сброса.
- Копия обучения — JSON `{ type: 'logos-learning', v: 2, decks, progress, settings, learnLog, stats, spread }` (копия без `spread` при восстановлении разбрасывается, как старое сохранение; копия `v: 1` — с прогрессом по карточкам — переводится по словам).

## 4. Тесты

- `node --test tests/core.test.js tests/boundary.test.js tests/library.test.js` (или `npm test`) — ядро без браузера: экономика, обучение,
  сохранения и перенос старого сохранения; плюс проверка, что ядро не знает о странице и текстах; библиотека — разбор своего

## 5. Механика города

### Цены и производство
- Выпуск здания = база × **множитель уровня** (каждый уровень умножает: ×1.15 за ресурсы, ×1.25 / ×1.4 за Логос) × (1 + сумма постоянных бонусов знаний и чудес) × (1 + сумма благословений): благословения на один ресурс складываются (два ×2 = ×3).
- Постройка: каждое следующее здание того же типа дороже в **1.25** раза. Чудеса — по одному, цена фиксированная.
- Улучшение до уровня t = цена постройки × 1.5 × **1.65^(t−2)** ресурсами (`upCostBase`, `upCostGrowth`; до ноября 2026 рост был ×1.5); с 4-го уровня добавляются товары (15 × 1.65^(t−4); после «Финикийцев» — серебро 5 : 1), с 6-го — медь, на 8-м — бронза, с 10-го — железо.
- **Уровни за Логос 3, 5, 7, 9 — только λ** (`BALANCE.wisdomLevels`): 3-й и 7-й — малые (3 и 9 λ, выпуск ×1.25), 5-й и 9-й — большие (`lp` и `lp × 3`, выпуск ×1.4). Уровни за ресурсы 2, 4, 6, 8 — ×1.15.
  Дальше — по три уровня на эпоху: два за ресурсы и один за Логос с новым обликом (×1.4): железный век — 10, 11 и 12-й (`lp × 4`),
  эллинский — 13, 14 и 15-й (`lp × 5`). До ноября 2026 было по два: 10-й и 11-й (`lp × 6`), 12-й и 13-й (`lp × 9`).
  `lp` (цена 5-го уровня): жилище 8; поле, загон, лесорубы, каменоломня, виноградник, роща 10; мастерская, склад, рудник, гавань,
  литейня, кузница, дом писцов 12 (до ноября 2026 — на 2 больше, у кузницы на 4).
  Для игрока: «уровни за ресурсы» и «уровни за Логос», без слов «труд/мудрость/символический». В Кипропедии и в окне здания — «рост к прошлому уровню» (×1.15 / ×1.25 / ×1.4), облик по уровням не показываем — сюрприз. Предел уровня: 5 в медно-каменном веке, 9 в бронзовом (9-й — венец: «всё лучшее»). 1 раунд ≈ 55 λ — ориентир для всех λ-цен.
- Работники: базовое число здания + 1 за каждый уровень за Логос (`Game.wisdomCount`; до 9-го — то же, что +1 за каждые 2 уровня). Места в жилище: round(4 × множитель уровня) + бонусы.
- **Нехватка рук:** сначала руки получают поля и загоны (здания, дающие зерно без сырья) — зерно работает на 100%;
  остальные делят оставшихся. Только если людей не хватает даже на поля, слабеет и зерно.
- **Переработчики** (гавань, литейня) не тратят сырьё на то, что не помещается: все выходы полны — здание отдыхает,
  часть полна — сырья уходит пропорционально меньше (у гавани: одно из двух полно — меди вдвое меньше).
- Склады: общий предел на каждый ресурс, 300 без построек + Склад (400 × множитель уровня) + бонусы.
  **Цена больше вместимости недоступна вовсе.**
- Каждый житель ест 0.05 зерна/с; рост — 1 житель за 6 с при свободных местах и зерне > 5; при голоде люди уходят.

### «Хозяйство в цифрах» (Кипропедия)
Живая страница «📊 Хозяйство в цифрах» (`a:income`) — три расчёта по городу игрока.
**Доход по ресурсам:** по каждому ресурсу — строки «здание · уровень × сколько»
с расчётом `база × уровень × (1 + бонусы) × (1 + благословения) × занятость`, сырьё переработчиков, еда жителей,
простаивающие/отдыхающие здания, источники бонусов и что дал бы «Сбор припасов». Данные — `Game.incomeBreakdown()`:
тот же цикл `Game.production()`, что и в такте (с журналом вкладов), поэтому сумма строк всегда равна доходу в шапке.
**Логос за карточки:** цена задания × множитель, из чего сложен множитель (`Game.logosBreakdown()`), когда снова доступны λ-благословения,
сколько сейчас даёт каждое задание и раунд. **Склады:** (база + склады + прибавки) × (1 + проценты) — `Game.storageBreakdown()`.

### Ценник ресурсов (мерка для баланса)
Сколько секунд работы одного жителя стоит единица ресурса (1-й уровень, без бонусов), в пересчёте на зерно:

| Зерно | Дерево | Камень | Сыр | Товары | Медь | Бронза | Железо | Серебро | Амфоры |
|---|---|---|---|---|---|---|---|---|---|
| 1 | 1.4 | 2 | ~1 (редок: только загоны) | 5 | 5 | ~29 | ~24 | 25 (= 5 товаров) | ~3.3 |

Считается из `BUILDINGS`: поле 2 работника → 0.5 зерна/с (4 с труда за зерно), каменоломня 2 → 0.25 камня/с (8 с) и т. д.;
сыр — остаток загона после зерна, бронза — труд литейни плюс медь. Переработчики выходят «в ноль»: гавань
(3 работника + 0.096 меди → 0.1 товаров + 0.525 зерна; с «Кожаными слитками» +25% работник гавани даёт столько же, сколько в поле или мастерской), литейня. Лишнее зерно на практике стоит меньше — его в основном съедают.
По этому ценнику сверяются обряды (ценность на 1 λ), а дальше — знания, переходы и будущий бот.

### Два пути к знаниям
У каждого знания два именованных пути (`paths`): 🧠 «с умом» — λ и немного ресурсов; 💪 «через силу» — без λ,
ресурсы ×3 плюс каждый λ цены заменяется 8 ресурсами (в медно-каменном веке дерево/камень пополам, в бронзовом — камень 40%, дерево 40%, товары 20%).
В медно-каменном веке λ «с умом» пересчитаны по курсу обрядов (1 λ ≈ 120 зерна — оба пути стоят одинаково): 7 / 12 / 18 / 28 / 30 / 60 λ,
а путь «через силу» оставлен прежним — он считается от старых цен (`laborLogos` у знания: 30 / 40 / 50 / 60 / 80 / 150).
В царствах-городах путь «через силу» — **закупка за рубежом** (`buy` у знания — что платят за каждый λ прежней цены `laborLogos`):
до «Финикийцев» — медью и товарами, после — серебром (товары в ценах сами становятся серебром), лес и камень — где к месту
(печи, террасы, рукояти, корабли), железо — в орудия, флот и чудеса. Путь «ресурсами» эпохи — ×2.7 к прежнему; λ «с умом» — по курсу
(1 λ ≈ 1650 зерна): 55 / 50 / 70 / 90 / 110 / 100 / 125 / 120 / 165. **«С умом» — не только λ**: ресурсы этого пути (`cost`) ×1.5 к прежним
(чтобы λ не решал всё сам, «λ to win»), а «через силу» прежний до единицы: он считается от прежней ресурсной части `laborBase`
(`techPrice(T, 'labor')`: `laborBase || cost`), поэтому λ по курсу чуть меньше. Обязательные чудеса царств — Саламин, Святилища Афродиты и Аполлона
(весомые в обычных ресурсах): Саламин — 450 λ + камень 10000, железо 2500, сыр 8000 (после «Виноградарства» — 4000 амфор),
дерево 10000, медь 1500; Афродита — 600 λ + камень 6000, сыр 9000 (потом 4500 амфор), медь 1500; Аполлон — камень 10000, медь 3000, железо 1200.
**Серебра в чудесах царств нет** (кроме 120 у вазы Амафунта): его забирает дань, копить его на чудо нельзя. Прежнее серебро
(Саламин 4000, Афродита 1500, склоны Троодоса 600) пересчитано по цене вывоза: гавань платит за амфору ≈ 0.6–0.7 серебра
(0.3 и бонусы: «Финикийцы», «Кожаные слитки», Саламин), значит, 1 серебро ≈ 1.5 амфоры = 3 сыра; где амфор вышло бы больше
полсклада (гавань продаёт всё, что сверх половины), остаток — медью и деревом по ценнику балансера (бронзовые котлы и колесницы
гробниц). По ценнику балансера (амфора там стоит трудом, 6.5 зерна) путь «ресурсами» царств стал на 2.5% легче. Пересчёт шёл
по тогдашней цене вывоза с бонусами; после перехода вывоза на твёрдую цену (0.35 серебра) эти три чуда по труду легче прежнего серебра на 35–40%.
Самая большая разовая цена — 13 500 дерева в закупке «Железных орудий» и «Флота»: балансер ставит склады и под цены закупки.
Необязательные чудеса царств: Виноградные склоны Троодоса — зерно 10000, дерево 6000, амфоры 4000 (в 3.5 раза дороже прежнего,
окупаются ≈ 2 ч без учёта вакханок); Каменную вазу Амафунта можно ставить и на равнине, и на холме.
Знания эллинского Кипра (`buy: true`) — пока старое правило: каждый λ заменяется `BALANCE.laborSilverPerLogos` = 0.75 серебра.
С эпохами путь «через силу» жёстче: вся его цена умножается на `BALANCE.laborEpochMult[эпоха]` (медно-каменный ×1, бронзовый ×1.7,
железный ×1.5, эллинский ×2.25 — железный и эллинский ещё пересмотрим).
**Бронзовый век пересмотрен:** «через силу» на 70% дороже прежнего (около 93 минут выпуска на «начале» эпохи на все знания вместо 55),
плюс ~25 тыс. зерна на знания (камень к печам, уголь к бронзе, тёсаный камень, рукояти к орудиям);
λ «с умом» — по курсу (1 λ ≈ 400 зерна): 35 / 35 / 60 / 60 / 70 / 85 / 50, всего 395 вместо 1070; λ-часть «через силу» — от прежних цен (`laborLogos`).
Обязательные чудеса бронзы весомые и в обычных ресурсах: дворец — камень 4000, дерево 3000, товары 600 (и 260 λ),
святилище Рогатого бога — камень 4000, медь 1200, товары 800 (и 330 λ).
Сыр — в «Мореходстве» (припасы) и «Письме» (учёт запасов).

### Улучшения зданий
Цена улучшения за ресурсы — цена постройки × 1.5 и ×1.65 за каждый следующий уровень (плюс товары с 4-го, медь с 6-го, бронза с 8-го).
Рост ×1.65 (был ×1.5) и `lp` на 2 меньше (у кузницы на 4) — чтобы уровни за ресурсы и за λ окупались ближе друг к другу:
у поля в бронзе всё в пределах 7 мин…2.2 ч, в царствах ресурсные — до 2 ч, λ-уровни — 5–10 ч (было до 12.4). Числа ниже в этом разделе — ещё при ×1.5.
Рудник, гавань и литейня поэтому стоят недорого (дерево 110 + камень 80; дерево 150 + камень 90; камень 100 + медь 40): их улучшения окупаются
в 1.5 раза (литейня — в 2 раза) дольше, чем у мастерской (2-й…8-й уровни: около 50 мин…3.5 ч; литейня — до 4.5 ч), а не 4–15 часов, как было.
Кузница стоит как литейня (камень 100 + медь 40, было 350 + 150): в царствах её уровни за ресурсы окупаются около 1–5.5 ч (вдвое дольше мастерской),
а не 4–19 ч. В железном веке окупаемость уровня в 4 часа — норма: уровни за λ у поля и мастерской — около 4.5–14 ч.

### Чудеса древнего Кипра
По мотивам реальных памятников (Лемба, Троодос, Суской, Хала-Султан-Текке, Энкоми, Аласия…). У каждого **одна цена**:
либо λ + скромные ресурсы, либо много ресурсов без λ. Чудо можно **убрать на склад** и бесплатно поставить в другое место;
на складе его бонус не действует, но для перехода эпохи оно засчитывается.
**Чудеса эпохи** (`retire` в `BUILDINGS`): Лемба и Мастера Суской при переходе в бронзовый век становятся домом и мастерской 5-го уровня
(`Game.retireWonders`, запись летописи `retired`, строка в окне новой эпохи). Об этом предупреждают карточка чуда, его окно, Кипропедия и вкладка «Эпоха».
Чудо со склада в новой эпохе ставится уже таким зданием. Бывшее чудо не поднимает цену следующего дома/мастерской. Святилище богини и Троодос не устаревают.
В железном веке так же уходят чудеса бронзового: Хала-Султан-Текке становится гаванью 7-го уровня, Святилище Слиткового бога — бронзолитейней 9-го
(литейню потом, после «Железа», можно перестроить в кузницу 9-го уровня или продать). Цены необязательных чудес — по окупаемости (балансер, раздел 11),
а остаток после устаревания — проверка, что переход не обидный.

### Обряды
- «Сбор припасов» — мгновенно всё, что здания производят за 3 минуты, за 9 λ, раз в 2 минуты (стоит отдельно, сверху вкладки).
  Считается **выпуск зданий без вычета расхода** (`Game.grossRates`): без благословений; сырьё переработчиков, еда жителей и продажа амфор
  гаванями не вычитаются, прибавка железных орудий считается. Раньше брался чистый выпуск — и при полных складах обряд не давал амфор
  (гавани продавали излишек), а при прожорливых кузницах — дерева.
- Благословения — множители на время; продлеваются до 30 минут; **одновременно не больше 5**.
  Благословения длятся 10–20 минут («Всей семьёй» — 30), λ-благословения святилищ («золотые часы») — 12 минут, под учёбу (со Стоей Зенона — 15). «Всей семьёй» удваивает рабочие руки. В бронзе и царствах у обрядов свои цены по курсу (`logosAt`: труда 18, поля со стадами 10, праздник 50, рудокопы 15, урожай 12 — прежние, по курсу худо-бедно годятся); в эллинском Кипре — пока цены царств (`logosAt` 3: урожай 12, труда 18, праздник 50, рудокопы 15, торговля 28, сбор винограда 12;
  по курсу урожай и виноград дешевле, торговля дороже), а со второй трети урожай, труд и праздник сменяют «Фалисии», «Халкеи» и «Афродисии» (18 / 35 / 140 λ, по курсу — см. «Эллинский Кипр»); обряды без `logosAt` стоят ×1.5 λ за эпоху —
  кроме «Всей семьёй» (`fixedPrice`: всегда 15 λ), зато он с каждой эпохой длится на 5 минут дольше (`durPerEpoch`, `Game.ritualDur`: 30/35/40/45).
  «Сбор припасов» даёт `BALANCE.suppliesMin` минут выпуска (`Game.suppliesSec`): 3/4/5/6 — с каждой эпохой на минуту больше.
  Числа, растущие с эпохами, в описаниях обрядов — заглушки `{min}`, `{supply}`, `{floor}` (подставляет `Looks.riteDesc`).
- Благословения на один ресурс складываются (Урожай + Праздник = зерно ×3) и умножают постоянные бонусы.

| Обряд | λ (в бронзе) | Действует |
|---|---|---|
| Сбор припасов | 9 (16) | сразу 3 мин выпуска всего (в бронзе — 4), раз в 2 мин |
| Всей семьёй | 15 (15) | руки ×2, 30 мин (в бронзе — 35) |
| Обряд труда | 18 (18) | дерево и камень ×2, 10 мин |
| Благословение полей и стад | 10 (10) | поля и загоны ×2, 10 мин + коза; до «Виноградарства» |
| Обряд урожая | 12 (в царствах) | зерно ×2, 10 мин; после «Виноградарства» |
| Праздник плодородия | 40 (50) | всё ×2, 20 мин, рост ×3 |
| Наблюдение за звёздами | — | λ +50%, 15 мин, **раз в 4 часа** (сыр, товары, зерно) |
| Обряд рудокопов | 15 (и в царствах) | рудники, литейни и кузницы ×2, 15 мин (по зданиям, а не по ресурсам: после «Медной монеты» «медь ×2» удвоило бы все монеты) |
| Обряд торговли | 16 (в царствах 28) | гавани и мастерские ×2, 20 мин (бронзу литеен удваивают только рудокопы; вывоз амфор — вдвое больше по той же цене, это не прибыль); в бронзе — со Святилищем Слиткового бога, с железного века — у всех (`reqUntil: 2`) |
| Толкование знамений | — | λ +75%, 15 мин, **раз в 8 часов** (медь, товары, сыр) |

**Курс обрядов** (ориентир): 3 λ = 1 минута выпуска города на начало эпохи; «начало» — не сам переход, а чуть позже: четверть пути
от перехода к концу эпохи (геометрически; в бронзе 18 → 27 зерна/с, 1 λ ≈ 400 зерна); для медно-каменного века — треть выпуска конца эпохи,
сколько это зерна за 1 λ — балансер, раздел 9 (сильно зависит от бюджета λ на уровни в разделе 8). «Сбор припасов» стоит ровно по курсу (`perMinute`: 9 λ за 3 минуты).
Базовое правило: 1 минута полного выпуска = `BALANCE.riteRate` = 3 «настоящих» (медных) λ. λ с эпохами дешевеет — `BALANCE.logosInflation`:
в бронзе номинальный λ — 3/4 медного (λ на треть больше даже при одном доме писцов), поэтому «Сбор» в бронзе — 4 минуты × 3 × 4/3 = 16 λ.
В царствах-городах минута выпуска стоит уже 3/1.3 ≈ 2.3 медных λ (λ становится ценнее), а инфляция λ — ×1.7: номинально снова ≈3.9 λ за минуту;
при мощи ~100–110 зерна/с на «начале» 1 λ ≈ 1500–1650 зерна. «Сбор» в царствах — 5 минут × 3.9 ≈ 20 λ.
В эллинском Кипре минута выпуска — 1.8 медных λ, инфляция ×2: 3.6 номинальных λ за минуту; мощь при переходе ~193 зерна/с, на «начале»
(по описанной первой трети) ~218 → 1 λ ≈ 3200–3600 зерна; «Сбор» — 6 минут × 3.6 ≈ 22 λ (было 31 по костылю). Остальные обряды эллинского — пока старый костыль: ×1.5 за эпоху. Благословения переводятся на него по очереди:
их цена — сколько минут выпуска города они в сумме прибавляют (на один ресурс, зато 10–30 минут). Переведены «Сбор припасов»,
«Обряд труда» (около 6 минут выпуска — 18 λ) и «Благословение полей и стад» (по курсу около 14 λ, но зерно и сыр в медно-каменном веке
в основном лишние — около 8% трат эпохи, поэтому считается половина благословения плюс коза: 10 λ).
Необязательные чудеса за λ — по окупаемости: эффект за время до перехода (около часа) плюс то, чем чудо станет потом
(Лемба и Мастера Суской — по 40 λ: окупаются примерно за 1.5 часа; мастерские +100%). «Праздник плодородия» оставлен за 40 λ: 20 минут удвоения всего —
это 20 × 3 = 60 λ по курсу, но он растянут на 20 минут и просит подношения. Траты λ медно-каменного века на этом все пересмотрены
(обязательные — святилище и переход — не балансируются: выбора нет, важно лишь ровное нарастание сложности).

### События
- Беглые козы: появляются раз в 2–4 минуты (`BALANCE.goatEvery`; с Троодосом — раз в 1–2 минуты, `goatEveryFast`) на 14 секунд; поимка даёт либо 4 минуты производства одного ресурса,
  либо 1 минуту всех (с минимумами).
- Набеги «народов моря» в бронзовом веке: через случайные 5–30 минут игры (`BALANCE.raidEvery`), срок виден заранее — красная плашка
  с обратным отсчётом справа в полосе над картой (`Game.raidIn()`), после каждого набега новый срок. Уносят случайно 10–50% всех запасов
  (`BALANCE.raidLoot`), λ не трогают. Пока игрока нет, отсчёт идёт; если срок подошёл — набег ровно один, в конце офлайна
  (после прибавки), затем отсчёт с начала (новый `nextRaidIn()`). Циклопические стены отражают набег (без трофеев)
  и дают +50% к складам (в эллинском после «Цистерн и бань Вуни» стены — склад 9-го уровня, +50% даёт знание).
- Набеги и дань идут с бронзового века, пока не изучена «Поддержка Александра» (`Game.raidsOn`: `effect.noTribute`).
- **Дань** в железном веке (`Game.raidKind() === 'tribute'`): тот же таймер, «народы моря» в неё «превращаются».
  Кто и как берёт — `Game.overlord()` (по знаниям):
  - 🏹 **Ассирия** (с начала эпохи) грабит: те же 10–50% всех запасов, стены — вдвое (`halved`).
  - ☥ **Египет** (после «Дани фараону») берёт серебром столько, сколько в среднем унесли бы ассирийцы: 30% ценности остальных запасов
    по ценнику (со стенами 15%), без случайности (`Game.tributeDue()`, сумма на плашке и растёт вместе с запасами).
    Формула: дань = ⌈⌈Σ запас·ценник ÷ 25 × 0.3⌉ × (1 − 0.25 с «Флотом царей»)⌉, где Σ — по всем видимым запасам, кроме серебра
    и привозного папируса, ценник — `BALANCE.worth` (зерно 1, сыр 1, дерево 1.4, камень 2, амфоры 3.3, товары и медь 5, железо 24,
    бронза 29), 25 — ценник серебра, 0.3 — середина `raidLoot` (0.1–0.5), со стенами 0.15.
    Не хватает — забирают всё серебро, недостающую долю добирают грабежом (10–50% × доля недоплаты, стены — вдвое).
  - 👑 **Персия** (после «Даров царю царей») — твёрдая подать: при изучении знания (`fixTribute`) сумма считается один раз
    (`state.tributeFixed` = `BALANCE.tribute.persia` = 4 с жителя) и дальше не растёт. Недоимку берут ровно по ценнику (`BALANCE.worth`) одной долей из всех запасов.
  - «Флот царей» −25% к дани Египту и Персии (`effect.tributeCut`). Плашка спокойная, когда серебра на дань хватает.
  Итог `Game.raid()`: `{ lord, due, paid, short, lost, pct, halved }`; текст — `Msg.tributeLine` (всплывашка, летопись, «С возвращением!»).
  Тяжесть: Египет ≈ средний ассирийский грабёж, только серебром (остальные запасы целы); Персия — мягче: в городе на ~170 жителей
  со складами на 26k и запасами в 20–35% Египет просит 1200–2000 серебра (со стенами), Персия — около 670 и дальше не растёт.

### Железный век («Царства-города»)
Идея эпохи: **серебро — деньги царей, железо — их сила**. Цари Кипра живут между империями и откупаются серебром.
- Предел уровня **12** (`EPOCHS[2].maxLevel`). Переход: 150 жителей, Царские гробницы Саламина, все 9 знаний, 400 λ,
  серебро 2500, железо 1500, камень 10000. Переход ведёт в эллинский Кипр.
  Старые сохранения, где переход был «концом прототипа» (`finished`), при загрузке снова открываются (`load`: эпоха больше не `locked`).
- **10-й и 11-й уровни** — за ресурсы, ×1.15, и вместо бронзы просят **железо** (`BALANCE.ironFromLevel`). **12-й** — за Логос, ×1.4,
  цена `4 × lp` (`wisdomLevels[12]`), с железным нарядным обликом.
- **Склады** с 10-го уровня растут резче: ×1.2 за ресурсный уровень и ×1.5 за уровень за Логос вместо ×1.15 и ×1.4
  (`BALANCE.storeGrowth`, `Game.storeMult`; до ноября 2026 — ×1.3 и ×1.6 на 10–13-м). Склад 12-го — 4628, 15-го — 9996.
- Ресурсные уровни дорожают в 1.65 раза за уровень, и 11-й у гавани (дерево ≈20 тыс.) и виноградника (≈16 тыс.) в склад конца
  железного века (≈14 тыс. по балансеру) не влезает — нужны лишние склады.
- **Перемены** (`retire` у знания в `TECHS`, код — `core/city/changes.js`):
  - `retire.res: { старый: { into, rate, stock, prodToo } }` — при изучении запасы переходят в новый ресурс по курсу `stock`
    (по умолчанию = `rate`; `stock: 0` — запасы просто пропадают, как бронза) (`applyRetire`,
    запись `resRetired`); все цены со старым ресурсом пересчитываются (`Game.liveCost` в ценах построек, улучшений, знаний,
    обрядов и перехода); бонусы к старому ресурсу переходят на новый (`Game.liveKey` в `effects`); старый ресурс пропадает из шапки.
    `prodToo` — здания продолжают работать, выпуская новый ресурс по курсу (для ремёсел → серебро); без него выход старого ресурса
    просто пропадает, и переработчик без выхода встаёт целиком, не тратя сырья и не занимая работников.
  - `retire.buildings: { старое: новое | { местность: новое } }` — тип устаревает: новые не строятся, в окне здания —
    «Перестроить» (тот же уровень, цена — базовая постройка нового; запись `rebuilt`) или «Продать» (весь λ его уровней за Логос
    + половина базовой цены; запись `sold`). Обычного «Снести» у устаревших и доживающих зданий нет — только «Продать»
    (`Game.demolish` отказывает, если есть `sellInfo`). Статья Кипропедии `a:changes`.
- **Улучшение чуда** (`upgradeOf` в `BUILDINGS`, `Game.upgradeWonder`): новое чудо встаёт на место старого (в городе или на складе),
  старое больше не строится (`Game.upgradedFrom`), обряды со старым `req` работают и при улучшенном (`Game.hasWonder`).
  Святилище богини → Святилище Афродиты Пафосской, Святилище Рогатого бога → Святилище Аполлона Гилата,
  Пастушьи тропы Троодоса → Виноградные склоны Троодоса (после «Виноградарства»). Кнопка «Улучшить» — во вкладке «Строить» и в окне чуда.
- **Обряды меняются**: `until` (уходит, когда святилище улучшено), `untilTech` / `tech` (уходит / появляется со знанием);
  обряд чуда прошлой эпохи прячется. «Наблюдение за звёздами» → «Таблицы Утренней звезды» (+100%, раз в 8 ч),
  «Толкование знамений» → «Гномон и полос» (+75%, раз в 4 ч), «Благословение полей и стад» → «Праздник лозы и оливы» (виноградники и рощи; был «Праздник сбора винограда») и «Обряд урожая».
  Подношения новых обрядов заданы в старых ресурсах и пересчитываются сами (`liveCost`).
- **Торговая линия** (`trade` у здания, `Game.tradeOf`): работает той же рабочей силой и только если есть сырьё — основная работа
  от неё не зависит. Гавань после «Виноградарства» продаёт амфоры за серебро сверх обычного — только то, что сверх половины склада (`trade.keep: 0.5`): до этого амфоры копятся.
  Линии двух пород: **продажа** (`trade.sell`, гавань) — бонусы и благословения растят объём (и сырьё, и выручку), цена твёрдая;
  **переработка** (орудия) — как основная работа здания: бонусы растят выход, сырьё идёт по базе. Лесорубы и каменоломни после
  «Железных топоров и кирок» тратят железо (0.005/с на 1-м уровне) и дают +30% дерева и камня. Подсказка у фишки — `tradeNote` в словаре.
- Устаревшие здания на карте серые со значком 🔄, работников не держат, не улучшаются.
- **Балансер** — страница `tools/balance/balancer.html`: открыть с диска двойным щелчком, считает движком игры прямо в браузере.
  Разделы — по порядку: 1) ожидаемые здания и бонусы-множители (а) без необязательных чудес за λ, (б) с ними; 2) население и склады;
  3) множитель λ; 4) курсы ресурсов в зерне; 5) выпуск города в зерне; 6) вся наука «с умом» и «через силу»; 7) обязательное в λ;
  8) все постройки и улучшения; 9) курс «λ ↔ ресурсы»; 10) полные затраты эпохи в двух сценариях — для начала и конца каждой эпохи.
  Сколько зданий каждого типа к концу эпохи — допущение, правится прямо в разделе 1 (только до перезагрузки: страница ничего не хранит в браузере, числа всегда из кода). Уровни — не предел эпохи:
  ресурсы игрок тратит до последнего, а на уровни за λ — бюджет эпохи (по умолчанию 100 / 300 / 500 / 1000, правится в разделе 8 «λ-бюджет улучшений»):
  сначала склады под самую большую цену эпохи, жилища под население перехода, дома писцов — пока окупаются, остальное — ровно.
  В итоге (раздел 10) λ — номинал и реальные (в медных λ: номинал ÷ инфляция λ, `BALANCE.logosInflation`).
  **Цель пути «ресурсами»** — `TARGET` в `balancer-core.js` (пока только эллинский: 7 млн зерна на всю эпоху, из них знания «через силу» — ≥5 млн; эпоха описана целиком, `part` = 1).
  Для недописанной эпохи цель части — доля по выпуску: части равны по времени, город растёт, как в описанной (в ×g за часть), — на первую из n
  частей приходится (g − 1)/(gⁿ − 1); в эллинском g ≈ 1.3 → ≈23%: на первую треть ≈1.6 млн пути и ≈1.1 млн знаний (ровно треть — 1.67 млн).
  Знания первой трети ≈1.22 млн, второй — ≈1.69 млн. Показана в разделе 10 и в `npm run balance`;
  «что если» для цен эллинских знаний — `node tools/balance/hellenic-techs.js '<buy>'`.
  Папирус в балансере стоит по «настоящей» цене — `BALANCE.ships.price` = 50 монет за лист (≈950 зерна); балансер проверяет и пакеты
  кораблей: каждый — ≈40 монет за лист по курсу эпохи (строка «корабли» в `npm run balance`, заметка в разделе 10).
  11) окупаемость необязательных чудес: прибавка к выпуску на середине эпохи, за сколько окупается, справедливая цена за N часов (по умолчанию 1.5).
  Расчёт — `tools/balance/balancer-core.js` (по умолчанию — `PLAN` в нём); `npm run balance` печатает короткую сводку в консоль.
  По умолчанию считаются все открытые эпохи — до римского Кипра включительно (`DEFAULTS.last` = 4). Римский Кипр описан на треть:
  `TARGET[4]` — 16 млн на эпоху (знания — 13 млн), `part` ⅓; `PLAN[4]` — город конца эллинского, `BUDGET[4]` = 0 (новых уровней пока нет),
  обязательное чудо — из `EPOCHS[4].must` (перехода ещё нет). Выпуск ≈254 зерна/с, 1 λ по курсу обрядов ≈4 700 зерна.

### Эллинский Кипр
Классика и эллинизм, ок. 480–58 до н. э. Идея эпохи: **монета, папирус и море** — Кипр на перекрёстке между Пиреем и Египтом,

  доля = недоимка ÷ всё хозяйство без папируса по полцены.
  При переходе в эпоху срок — заново (`advanceEpoch`). В среднем 6000 монет за 20 минут — ≈5 монет/с, ≈90–110 зерна/с при выпуске ≈260.
- **Знания** (цены «с умом» — по курсу ≈4700, «через силу» — числами, `labor`: по ценнику 40% папирус, 30% монеты, 30% остальное —
  монеты копить мимо откупщиков, склады растить): «Эдикт Цицерона» (110 λ; открыт сразу; «через силу» — 80% цены папирус и без монет:
  знание против откупщиков) → «Скамья Гиппократа» (120 λ; Аполлоний Китийский; +2 места в жилищах, жители быстрее — как «Врачи Идалиона»)
  и «Pax Romana» (130 λ; «Обряд торговли» → **Меркуралии**) → «Милость Августа» (140 λ; открывает Римский храм Афродиты Пафосской).
  Стадион Куриона пока спрятан (рисунок `t_kourion` готов) — ждёт бонуса и названия.
- **Меркуралии** (`ship: true` у обряда): гавани и мастерские ×3 на 15 минут, и сразу приходит корабль — стоящий у причала уходит,
  новый приходит со всеми сделками; перерыв — минута; 40 λ (≈1.5 «Обряда торговли» по курсу и корабль).
- **Римский храм Афродиты Пафосской** (`sp_paphia`, улучшение Святилища Афродиты): её прежнее и монет +20%; 600 λ и ≈240 тыс. зерна
  ресурсами, без монет. Обязательное чудо эпохи.
- Прежние обряды — по курсу эпохи, на десятую дешевле эллинских (`logosAt[4]`): минута выпуска стоит 3.2 λ, а не 3.6.

### Офлайн
Игра «спит» во вкладке в фоне. При возвращении (`Game.catchUp`): считается настоящее время отсутствия, максимум 8 часов.
Выпуск и рост — первые 5 минут в полную силу, дальше вполовину; благословения и перерывы обрядов истекают по настоящему времени
(`Game.passTime`). Затем, если срок подошёл, — один набег по накопленному. Окно «С возвращением!» показывает прибавку,
жителей, закончившиеся благословения и потери от набега.

### Переход эпохи
Население, обязательные чудеса, все знания эпохи, запасы и немного λ (120 в бронзовый век, 250 — в следующий). Медно-каменный век по балансеру —
несколько часов игры (≈42 тыс. зерна при выпуске 6 → 18 зерна/с) и около дюжины раундов карточек (≈630 λ «с умом» по ≈55 λ за раунд).
Это единственное исключение из правила «одна тяжёлая часть цены».

**Логос по ходу эпохи — равномерно.** Крупные траты λ не должны копиться к концу:
- начало — первые знания и большое чудо без поздних ресурсов (Лемба; в бронзовом веке — Дворец Аласии);
- середина — обязательное святилище (богини плодородия — камень и товары; Рогатого бога — камень, медь и товары, без бронзы);
- конец — последнее знание эпохи («Первая медь» после «Красно-белой керамики»; «Бронзовые орудия») и высокие уровни зданий;
- переход — немного λ, главное — запасы и население.

**Ориентир по Логосу.** 1 раунд из 8 заданий ≈ 55 λ до бонусов (`ROUND_LAMBDA`). Медно-каменный век — около 10 раундов, бронзовый — ещё около 15.
Постоянный множитель λ: святилище богини +10%, писцы +8–26% (дом писцов один, после «Кипрского слогового письма» — два, после «Алфавита Эвагора» — три: `max: 1, maxTech`), Святилище Рогатого бога +20%. λ-благословения — «золотые часы»:
«Наблюдение за звёздами» +50% на 15 минут раз в 4 часа, «Толкование знамений» +75% на 15 минут раз в 8 часов. Перерыв идёт
по настоящим часам (`realTime`, `state.readyAt`), а не по игровому времени, — поэтому переживает уход из игры.

## 6. Обучение

### Раунд
- По умолчанию 8 карточек: сначала заучиваемые, потом те, что пора повторить, потом до 5 новых, потом досрочные.
- Новое слово: знакомство, а в конце того же раунда — проверка.
- Задания: «Что это значит?» (греч. → перевод), «Как это по-гречески?», «Соедините пары» (4 пары), «Вспомните сами»,
  **«Какая буква?»** (пропуск в трудном месте: ι/η/υ/ει/οι, ο/ω, ε/αι) и **«Соберите слово»**
  (короткое — из букв, длинное — из слогов, не больше 6 кусков, + 2–3 обманки, похожие на слух; можно печатать с клавиатуры).
- Варианты ответа берутся из той же колоды (та же часть речи).

### Встроенные колоды и уровни
- Id колоды начинается с уровня: `a1-…`, `a2-…`, `b1-…` (`Decks.levelOf`); в «📚 Обучении» колоды сгруппированы по уровням,
  уровень можно включить целиком. Колоды A2 и B1 приходят выключенными (`"off": true`), A1 — включёнными.
- Источник — учебник «Κλικ στα ελληνικά» (A1/A2/B1). **Правило уровня — гибридное:** основа — уровень из учебника,
  поправка — частотность (zipf): слово из B1 учебника, которое по частотности A1/A2, считается A2. Из этого пула слова
  отбираются вручную: учебниковые «базовые» слова, ошибки разбора (ударения, опечатки, части речи) и редкая лексика отсеиваются.
- **Правила отбора — `tools/words/LEVELS.md`** (обязательно перед пополнением колод): тест A1 из трёх вопросов, что в A1 не идёт
  никогда, гибридное правило A2/B1, переводы, размеры колод, порядок работы.
- **A1 строже (с v10):** «есть в учебнике A1» ≠ «ядро A1» — словарик учебника перечисляет все слова своих текстов. В A1 — слова тем
  уровня А1 Κέντρου Ελληνικής Γλώσσας (имя, возраст, страна, семья, профессия; жильё; погода и природа; досуг; праздники; тело и врач;
  покупки и цены; еда, заказ и счёт; учёба и работа; банк и почта; транспорт и гостиница), служебные слова, самые частые глаголы
  и прилагательные; отвлечённое и книжное — в A2. Ориентир объёма — Goethe-Zertifikat A1: «circa 650» слов, из них активных половина;
  у нас A1 ≈ 630 карточек + стартовый набор. Частотный список (новостной корпус) тут не судья: τρώω, γάτα, αδερφός в нём — «B1».
- **«Что будем учить?»** — вопрос в начале каждой новой игры (после вступления; если игрок закрыл окно — перед первым раундом,
  флаг `planPending` в состоянии города). Ответ — **подборка колод**: `LEARN_PLANS` в `core/learning/decks.js`
  (`a1start` — «A1 · начинающий», `a1` — «A1+», весь A1, `a2`, `b1`, `verbs` — глаголы A1–B1, `own` — если есть свои колоды);
  подборка задаётся списком id колод (`decks`) или целыми группами (`groups`), тексты — `Lex.plan`.
  Подборка включает свои колоды и выключает остальные, прогресс не трогает. Если игрок уже учился, есть «Оставить как сейчас».
  Сменить — «📚 Обучение» → «Обзор» → «Сменить».
- Каждое греческое слово встречается во встроенных колодах A1–B1 **один раз** (кроме стартового набора); это проверяет тест.
  Варианты одного глагола (`συζητώ` / `συζητάω`) — тоже одно слово.
- **A1 — по темам (с v10):** знакомство и вежливость, семья и люди, профессии, числа, дни и время, еда и ресторан, дом, одежда и покупки,
  тело и здоровье, город и транспорт, погода и природа, учёба и работа, досуг, «самые нужные слова»; прилагательные (цвет и размер /
  оценка и чувства), наречия «где? когда?», связки, местоимения; глаголы — по спряжению (-ω ×2, -άω/-ώ, -μαι). Варианты ответа
  берутся из той же колоды — значит, из той же темы.
- A2 и B1 — колоды по грамматике, по 16–70 слов: связки и наречия; существительные ο / η / το; люди и профессии; прилагательные;

### Из чего состоит раунд
- **Раунд — ровно `roundSize` заданий** (6/8/12/16): знакомство с новым словом — тоже задание, его проверка в конце раунда — ещё одно;
  «Пары» (4 слова на экране) считаются за два задания, и раунд добирается повторением (`Lesson.plan`; добрать нечем — без «Пар»).
- **`learnPool` — сколько слов заучивается одновременно** («в ротации»), а не «новых за раунд»: новые приходят, пока заучивается
  меньше `learnPool`, не больше половины оставшегося раунда, и половина остатка (сколько нужно) — повторению выученного
  (`Decks.roundPlan` — без случайности, его же показывает подсказка «Учиться»; `selectRound` выбирает, какие именно новые).
  Например, 8 заданий и 8 слов: первый раунд — 4 новых и их проверка, дальше — заучиваемые вперемешку с новыми. Раньше при
  «8 новых за раунд» раунд мог быть 8 знакомств + 8 проверок, а мог — 8 повторений: несравнимая длина.
- Старые сохранения и копии: `newPerRound` → `learnPool` (`Decks.fixSettings`).

### Как слово становится выученным
- Шагов до «выучено» **ровно столько, сколько выбрано в настройках** (2–5). Ученика не нагружаем сверх выбранного темпа.
- **Последний шаг — всегда набор слова.** «Какая буква?» может попасться на любом шаге и считается шагом.
- Ошибка в переводе — шаг назад. **Ошибка в написании («Какая буква?», набор) шаг не откатывает**:
  перевод и написание — разные знания; слово просто ещё раз пойдёт на набор. Выученному слову после такой ошибки хватает одного верного набора.
- Выученное повторяется по «аппетиту»: редко / умеренно / часто (`APPETITES`).
  **Срок — со случайным разбросом:** ступень лестницы × случайно от 10% до 190% (`DUE_SPREAD`, в среднем — ровно ступень). Слова, выученные
  в один день, возвращаются вразбивку, а не волной через месяц; «долг» отрабатывается с первых дней. Сохранения до разброса
  разбрасываются один раз при загрузке (`Decks.respread`, флаг `spread` в `Learn.state`): срок = последний ответ + интервал × множитель.
- Ошибка набора: в наборе зелёное — верно, красное — неверно, оранжевое — не то ударение; в правильном слове выделено место ошибки.
  Никаких «вторых попыток» — неправильно значит неправильно.

### Награды
- λ зависит **только от типа задания**: набор 12, «Как по-гречески?» 7, «Какая буква?» 6, «Что это значит?» 6, пара 3, «Вспомните сами» 1;
  досрочное повторение ×0.4; знакомство — 0. **Серии верных ответов не поощряются.**
- Цель калибровки: **≈ 55 λ за раунд** (`ROUND_LAMBDA`) до бонусов святилищ и писцов. Цена задания видна в вопросе.

### Экран «📚 Обучение»
Отдельный, «спрятанный» экран (кнопка 📚 в шапке и ссылка в конце раунда): обзор и журнал по дням, колоды, таблица слов
с фильтрами, темп и награды, импорт/экспорт, сбросы. Кнопка «📜 Учиться» в шапке — без подписей; что будет в раунде («пора повторить 3, новых до 5») — в её подсказке, а когда нечего повторять и учить, она не мерцает.

### Библиотека (`library/`)
Отдельные страницы сайта для чтения греческих текстов: ссылки — статья Кипропедии «Библиотека: читать тексты» (раздел «Учёба»)
и низ меню экрана «📚 Обучение», открываются в новой вкладке. Нажатие на слово — перевод в этом предложении, словарная форма,
грамматика; слово внутри **оборота** (устойчивого выражения, *ρίχνω μια ματιά* — «взглянуть») — единица тогда весь оборот: он подсвечивается,
его перевод — главный в карточке, «Запомнить оборот» и поля — тоже целиком. Оформление — в стиле игры (пергамент, Noto Serif, шапка с меандром).
«Запомнить» — своя колода читалки с экспортом в Anki / Quizlet / Brainscape / CSV (с колодами игры пока не связана).
**Свой текст** разбирается в браузере по словарю сайта (`dict.js`: формы, леммы, обороты из всех книг — без предложений и текстов)
и сохраняется в «Моих текстах» — только в браузере посетителя (`localStorage`), с копией в файл и загрузкой из файла.
Связь с игрой — через общее хранилище браузера: карточки читалки вашего уровня (и ниже) сами становятся колодой
**«📖 Слова из чтения»** (`Decks.setReadingDeck`, `Reading.sync`); прогресс у слова общий для всех колод, выученное в игре
читалка показывает зелёным. В «Обучении» → «Колоды» у каждой группы — сколько выучено. Уровень текста — по покрытию 95/98%.
Книги собирает `tools/library/bookconverter.py`; на сайт — только тексты, которые можно выкладывать (`license` в `book.json`),
остальное — личная полка `library/local/` (только с диска). Подробно — `tools/library/README.md`.

## 7. Интерфейс

- **Шапка:** эпоха (только название; годы и «Энеолит» — в подсказке и во вкладке «Эпоха», шапка нужна ресурсам) → медальон λ
  (на почётном месте, под числом — бонус к Логосу) → ресурсы (число, прирост, полоска заполнения склада) → жители и работники →
  кнопки-кружки `.top-tools`: 📖 библиотека (ссылка `library/index.html`; в библиотеке обратно — золотая «🏛️ В игру»),

  **Прирост виден всегда.** Ресурсы не помещаются — ячейки становятся плотнее (`UI.fitRes`, `data-fit` 1–3: мельче → значок над числом →
  ещё мельче, на 3-й ленту можно прокрутить); обратно к крупным — только при смене ширины окна или числа ресурсов, чтобы шапка не дёргалась.

  Золотая подсветка — ресурс под благословением.
- **Полоса благословений** над картой: место под неё есть всегда (5 пустых кружков), никогда не переносится на вторую строку —

  каменоломня → вторая хижина («нужны люди»: рук не хватает) → раунд карточек — короткий, 4 задания (`round` у шага; `Lesson.plan(state, roundSize)`) →
  «Сбор припасов» → любое знание. Шаг, сделанный раньше очереди, засчитывается сразу (пояснение — только в свою очередь).
  За шаг — `BALANCE.tutorialReward` (3) λ, за пояснения — ничего: всего 24 λ на игру, награда одна (пропуск и возврат её не повторяют).
  - **Карточка задания** — над картой слева сверху (там море): точки шагов, задание, «λ +3», живая строка (счётчик, чего не хватает, сколько рук), ▾ свернуть, ✕ пропустить.
  - **Стрелка и рамка** (`position: fixed`, клики насквозь, z 450 — под окнами) показывают, куда жать: клетку у первой хижины (видимую, не под карточкой),
    вкладку, если открыта другая (на телефоне — кнопку полосы справа), потом кнопку в панели (на телефоне — карточку здания), клетку для постройки.
    Не хватает: λ — к «Учиться»; до 25 ресурса — на клетку, где его собирают («Собери 🪵 12»); больше — на число в шапке («копится…»).
    К панели справа стрелка идёт слева (остриём вправо), у верхнего края экрана — снизу, иначе — сверху.
  - Пропустили (или новая игра поверх прежней) — «🎓 Пройти обучение» во вкладке «Эпоха».
  - Проверка: эталон (`tests/golden.js`, сценарий 8 — игрок жмёт туда, куда показывает стрелка) и `npm run phone` (раздел 3).
- **Телефон** — пока внутри интерфейса ПК: та же разметка и `UI`, раскладка — `ui/desktop/phone.css`
  (`@media (orientation: landscape) and (max-height: 520px)`), сенсорное управление — `ui/desktop/phone.js`. Правил игры там нет.
  Принципы телефона:
  - **Только альбомная ориентация и полный экран.** В портретной — просьба повернуть; без полного экрана — заслонка
    «Играть на весь экран» (браузер даёт полный экран только по нажатию). На iPhone полного экрана из браузера нет —
    подсказка «Поделиться → На экран „Домой“» в предупреждении, а `manifest.webmanifest` открывает игру с главного экрана без панелей.
  - **Окна и панели — на весь экран**, если место не очевидно свободно: окно здания (двумя колонками), эпоха, план, раунд,
    Кипропедия, «Обучение», вкладки. Маленькие окна (подтверждение) — маленькие. Закрыть — **✕** в углу; кнопки окна
    прилипают к низу. Выдвижная панель подписана, откуда она («🔨 Строить»), карточки в ней — сеткой.
  - **Карта — на всю ширину**, а север и юг, что не влезли по высоте, листаются пальцем (`#mapScroll`); тень с ▲ / ▼ у края — там ещё есть
    карта; при запуске в середине экрана — город. Благословения и срок набега — узкой полосой слева от карты, не поверх клеток.
  - **Шапка:** ресурсы тянутся на свободное место (ячейка не шире 110), но соседей не давят — тогда ячейки плотнее; жителям и «Учиться» — крупный шрифт.
  - **Свернуть, а не уместить:** вступление эпохи — под катом, оглавление справки — по ☰, разделы «Обучения» — полоской значков,
    описания знаний и обрядов — в две строки (целиком — в справке по «?»).
  - **Значки вместо слов:** библиотека 📖, учёба 📚 и справка «?» — внизу полосы справа (`#rail`), на низком экране подписи у неё пропадают;
    у путей знания — 🧠 / 💪 и название пути; клавиши (`kbd`) на кнопках не показываются.
  - **Подсказки — долгим нажатием:** всё, что на компьютере всплывает под мышью (`title`), показывает `#touchTip`; отпущенный палец
    после подсказки — не нажатие (не строит, не собирает, не открывает).
  - **Shift+клик → режим ⏫:** пока он включён, каждое касание здания — +1 уровень; на карте зелёная стрелка — ресурсов хватает,
    золотая λ — уровень за Логос, бледное — нельзя. «Shift при строительстве» → кнопка **🔁 ещё** на плашке «куда поставить».
    Касание карточки во вкладке «Строить» (и здания, и чуда) — то же, что кнопка «Строить»: кнопки на телефоне нет, «выбрано» не подсвечивается;
    постройка всё равно в два шага (карточка → клетка). Только **улучшение чуда** касанием карточки не делается — оно сразу тратит много:
    открывается окно чуда с ценой и кнопкой «Улучшить» (чудо на складе — окно подтверждения);
    **?** — отдельный кусок карточки справа (статья в Кипропедии); не хватает ресурсов — карточка серая. У чуда значок — в строке с названием.

### Графика
- Иконки — рисованные SVG в поле 64×64, единая палитра и контур (`assets/art.js`). Эмодзи остаются только в тексте и журнале.
- Облик здания (`Looks.looks` / `Looks.icons` в `ui/common/looks.js`) зависит от **уровня**, а эпоха лишь добавляет свои верхние уровни —
  **каждая эпоха рисует только свои новые уровни**, нижние берут облик прошлых эпох (вместе с названием — `Looks.name`):
  | Здание | Медно-каменный век | Бронзовый век | Железный век |
  |---|---|---|---|
  | старое (медного века) | 1 `p0` · 3 `p1` · 5 `p1`+`p0` | 1, 3 — медные · 5 `p2` · 7 `p3` · 9 `p3`+`p2` | 1, 3 — медные · 5, 7 — бронзовые · 9 `p4` · 11 `p5`+`p4` |
  | бронзового века | — | 1 `p0` · 3 `p1` · 5 `p1`+`p0` · 7 `p2` · 9 `p2`+`p1` | 1–7 — как в бронзовом · 9 `p3` · 12 `p4`+`p3` |
  | железного века | — | — | 1 `p0` · 5 `p1` · 9 `p2` · 12 `p2`+`p1` |

  «`a`+`b`» — главный рисунок и рядом второй, поменьше. Облик меняется на 5-м уровне при переходе в бронзовый век
  (с лучшего медного на начальный бронзовый) и на 9-м — в железный.
  **Первый облик новой эпохи — базовый, «с нуля, но уже из нового материала»**: проще нарядного облика прошлой эпохи
  (одна постройка, мало утвари), зато сразу видно, из чего: бронзовые серп, топор, резец (5-й); железные лемех, топор, кирка,
  оковка двери, тёсаный камень (9-й). Нарядный — следующий облик эпохи (7-й в бронзе, 12-й в железе): так 9-й бронзовый
  выглядит богаче 9-го железного, а 5-й медный — богаче 5-го бронзового. Пары «нарядный + базовый» — 9-й бронзовый и 12-й железный. Нет рисунков новой эпохи (козий загон уходит
  с «Виноградарством», литейня — с «Железом») — остаётся лучший облик прошлой. Названия обликов — `forms` у здания
  (`Lex.bld[тип].forms[эпоха].name`): хижина 1-го уровня и в бронзовом веке зовётся «Круглая хижина».
- Железный век: тёсаный камень, протоэолийские колонны с завитками, серое железо, финикийский пурпур и серебро
  (9-й, базовый → 12-й, нарядный: дом с двором и железным треножником → дом с портиком; свежая пашня с железным лемехом → поле-усадьба
  с журавлём; бревно с железным топором и клином → верфь; ступени выработки с железной киркой → царская каменоломня с капителью;
  печь и кувшин «свободного поля» → мастерская серебряных дел; кладовая с окованной дверью → царская кладовая; галерея с киркой →
  рудник с плавильней; лодка у короткого мола и каменный якорь → корабельный сарай Китиона; палата со стелой слогового письма →
  царская канцелярия; кузница: горн → навес → царская кузница).
- На карте у гавани вода рисунка (во всю ширину, без рамки) продолжается бухтой до краёв клетки и сливается с морем рядом;
  у поля с 5-го уровня (один рисунок, не пара) — оросительный канал полосой по левому краю клетки во всю высоту, каналы соседних
  полей смыкаются (`canal` в `UI.renderMap`, `styles.css`). Своих каналов на рисунках полей нет.
- В Кипропедии рисунки обликов не показываем (сюрприз), только названия по уровням (строка «Облик»).
- Все рисунки разом, крупно и с замыслом автора — `tools/art/gallery.html` (собирает `node tools/art/gallery.js`, описания — `tools/art/notes.js`).
- **Облик с 4-го уровня должен отличаться заметно** (не «копеечка»): двор из двух хижин, двухэтажный дом, золотое поле, каменная овчарня…
  На карте здания 1–3 уровня рисуются мельче.
- Поля рисуются прямо на земле клетки, без тени и подставки.

## 8. Принципы и принятые решения

- **С умом или через силу.** У любой цены одна тяжёлая часть: либо много λ и немного ресурсов, либо много ресурсов без λ.
  Ничто не стоит одновременно много λ и много ресурсов. Исключение — переход эпохи.
- **λ первичен, но не обязателен.** Тратить λ можно с первых минут (обряды), но без карточек игра тоже идёт.
- **Рост вверх, а не вширь.** Земля на острове ограничена, поэтому новые эпохи не наращивают сложность количеством:
  в шапке остаётся около 7 ресурсов, в эпохе — 4–5 чудес, новых обычных зданий почти нет. Город растёт **уровнями**
  (предел +2 за эпоху: 5 → 9 → 11 → …) и **превращениями**: старое здание становится новым, старый ресурс уходит,
  его место занимает новый. Чем дальше эпоха, тем больше в ней апгрейдов и меньше стройки.
- **Перемены — мягко и посреди эпохи.** Эпоха начинается с привычного хозяйства прошлой, а старое уходит по ходу —
  через знания, а не разом на границе. Уходящее не пропадает даром: здание можно **перестроить** в новое (уровень сохраняется)
  или **продать** (вложенный в его уровни Логос возвращается, часть ресурсов тоже); запасы уходящего ресурса
  переходят в новый по ценнику труда. Драгоценный λ при переменах не теряется.
- **Длина эпохи.** Каждая следующая эпоха длиннее прошлой — заметно, но без скачка в «сверхжёсткость»: ориентир — примерно
  в 1.5 раза дольше по настоящему Логосу (по раундам, с учётом выросшего множителя λ) и до ~×3 по номинальным ресурсам
  в зонах утяжеления — с уровнями и бонусами по-настоящему это около ×2.
  Склады должны поспевать за ценами переходов: в эпоху с новыми уровнями склады на этих уровнях растут резче.
- **Путь «через силу» с каждой эпохой жёстче** (`BALANCE.laborEpochMult`): чем дальше, тем выгоднее учиться, а не таскать камни.
- **Зоны утяжеления — чудеса, знания и переходы эпох.** Только их цены от эпохи к эпохе специально поднимаются.
  Здания дорожают лишь по общим правилам (×1.65 за уровень, товары / медь / бронза / железо с нужных уровней, λ на нечётных,
  ×1.25 за каждое следующее того же типа) — их цены отдельно не утяжеляются.
- **Улучшение чуда не отнимает.** Чудо, выросшее из старого, сохраняет его λ-бонус и добавляет своё.
- **Учёба не наказывает и не надоедает:** серии не поощряются, ошибки не «сжигают» прогресс, всё укладывается в выбранный темп.
- **Обучение живёт отдельно от города:** новая игра его не трогает.
- **Интерфейс без лишних слов:** в панелях — цифры и иконки; правила и рассказы — в Кипропедии. Каждая статья начинается с мини-истории.
- **Слова вместо сокращений:** «работников», а не «работн.».
- **Историческая правда:** названия и сюжеты — по реальной археологии Кипра; картинки-иллюстрации — ссылки на Wikimedia Commons.
