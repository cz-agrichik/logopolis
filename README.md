# Λόγος · Кипр сквозь эпохи

Градостроительный симулятор по истории Кипра, совмещённый с изучением греческого.
Город растёт сам, но всё важное (знания, чудеса, высокие уровни зданий, переход эпох) требует **λ Логоса**,
а Логос даётся **только за верные ответы на карточки**. Играть можно и без карточек, но с ними заметно быстрее.

Сейчас в игре три эпохи — Медно-каменный век (энеолит), Бронзовый век (Аласия) и железный век «Царства-города»; дальше — заглушка-финал.
Встроено ~1050 карточек из учебника «Κλικ στα ελληνικά» с русским переводом: A1 (~485 слов, включены сразу),
A2 (~300) и B1 (~260) — выключены, пока игрок их не включит.

Этот файл — главный справочник по проекту: где что лежит, как устроены механики, какие решения уже приняты
и почему, как вносить изменения. Правила для игрока — в самой игре, в **📖 Кипропедии** (F1).

## 1. Запуск

- Открыть `index.html` в Chrome/Edge прямо с диска (`file://`). Сборки, сервера и зависимостей нет.
- `index.html?dev` — отладочные кнопки во вкладке «Эпоха»: +500 λ, +1000 ресурсов, коза, набег.
- `index.html?reset` — аварийный сброс сохранения.
- Скрипты и стили подключаются с `?v=ASSET_V`. **После любого изменения кода поднимайте одно число — `ASSET_V`
  в начале `index.html`**, иначе браузер возьмёт старые файлы из кэша. Список скриптов и их порядок — массив `ASSETS`
  в конце `index.html` (скрипты дописываются через `document.write`, синхронно и по порядку, как обычные теги);
  новый файл добавляется туда одной строкой. Тест `boundary.test.js` проверяет, что каждый `.js` из слоёв есть в списке
  и что номеров версий в странице больше нет. `tests/load-core.js` берёт список ядра оттуда же.
- Опубликовано: **https://grecheskiy.com** — GitHub Pages из этого репозитория (файл `CNAME`), DNS в Cloudflare
  (CNAME `@` и `www` → `cz-agrichik.github.io`, «DNS only»). После пуша сайт обновляется за минуту-две, `index.html` кэшируется до 10 минут.
- Яндекс Метрика (счётчик 114153547, вебвизор) — в `<head>` `index.html`; включается только по `https:`, поэтому запуск с диска и тесты в статистику не попадают.

## 2. Архитектура

Код разложен по слоям так, чтобы у игры могло быть **несколько независимых интерфейсов** (ПК, планшет, телефон,
A/B-варианты одного экрана) с общими правилами и общими текстами.

```
core/        ЯДРО — правила игры и обучения. Без страницы, без хранилища браузера, без текстов.
content/ru/  ТЕКСТЫ на русском: названия, описания, истории, сообщения, Кипропедия, встроенные слова.
assets/      РИСУНКИ (SVG).
platform/    ПЛАТФОРМА: хранилище, перезапуск страницы, озвучка — для браузера.
ui/common/   ОБЩЕЕ ДЛЯ HTML-ИНТЕРФЕЙСОВ: каталог (числа + тексты), облики зданий, мелкие хелперы.
ui/desktop/  ИНТЕРФЕЙС ДЛЯ ПК: шапка, карта, вкладки, раунд карточек, «Обучение», Кипропедия, стили, запуск.
tests/       ТЕСТЫ: ядро без браузера, границы слоёв, «золотой эталон» в браузере.
tools/       ИНСТРУМЕНТЫ (не часть игры): проверка Кипропедии, сверка цен эпох, листы рисунков, пополнение колод — tools/README.md.
```

**Правило зависимостей:** `core` ни от кого не зависит (кроме встроенных колод из `content/ru/words.js` — это данные).
`content` и `ui/common` читают `core`. Интерфейс (`ui/desktop`) читает всё. Ядро никогда не зовёт интерфейс —
оно сообщает о событиях через `Bus` и возвращает **коды**, а не фразы. Это проверяет `tests/boundary.test.js`.

### Как ядро говорит с интерфейсом

- **Команды** — методы ядра: `Game.build(type, x, y)`, `Game.upgrade(b)`, `Game.perform(id)`, `Lesson.answer(...)`…
- **Статусы и причины** — объекты с кодами: `buildStatus()` → `{ ok: false, reason: { code: 'lack', items: [['wood', 12]] } }`.
  Текст — `Msg.reason(reason)`.
- **Летопись** — записи `{ t, k: 'built', p: { type, epoch } }`; текст — `Msg.log(entry)`.
- **События** — `Bus.on('log' | 'raid', fn)`: например, набег показывает всплывашку.
- **Сводки** — `Game.labor()`, `Game.buffedRes()`, `Decks.roundPreview()`, `Decks.totals()`: интерфейсу не нужно знать правила.
- **Обучение** живёт отдельно (`Learn.state`): все функции `Decks`/`Lesson` принимают его параметром.
  Награда в λ считается в обучении, а начисляется в городе: `Lesson.answer(Learn.state, …, Game.logosMult())` → `Game.addLogos(gain)`.

### Как добавить ещё один интерфейс (телефон, планшет, A/B-вариант)

1. Новая страница, например `mobile.html`: подключить `core/*`, `content/ru/*`, `assets/art.js`, `platform/browser.js`, `ui/common/*`
   в том же порядке, что и в `index.html`, а затем свои скрипты из `ui/mobile/`.
2. Свой запуск по образцу `ui/desktop/main.js`: `Game.genMap()`, `Session.start(BrowserIO)`, игровой цикл, `Session.saveAll()`.
3. Рисовать из `Cat`, `Looks`, `Msg`, `PediaBook`; правила не дублировать — только звать ядро.
4. Сохранения общие: все интерфейсы в одном браузере видят один и тот же город и одно обучение.
5. A/B-вариант того же экрана — так же отдельной страницей (или выбором набора скриптов в `index.html` по параметру);
   ядро и тексты не меняются.

Подписи кнопок и короткие фразы конкретного экрана живут рядом с его разметкой (в `ui/<интерфейс>/`);
всё, что нужно нескольким интерфейсам (названия, описания, сообщения, справка), — в `content/ru/`.

### Где менять, если нужно…

- **число баланса** — `BALANCE` или конкретное здание/знание/обряд в `core/defs.js`;
- **название, описание, историю** — `content/ru/lexicon.js`;
- **текст сообщения** (причина «нельзя», запись летописи) — `content/ru/messages.js`;
- **новое здание** — числа в `core/defs.js`, тексты в `lexicon.js`, рисунки `<префикс>0, 1, 2…` в `assets/art.js` по схеме обликов (раздел «Графика»; проверить — `tools/art/looks.js`),
  префикс в `Looks.ART` (`ui/common/looks.js`), при желании совет в `TIPS` (`content/ru/pedia.js`);
- **новое знание** — `TECHS` (+ тексты и `paths` в `lexicon.js`, медальон `t_<id>` в `art.js`, история в `TECH_STORY`);
- **новый обряд** — `RITUALS` (+ тексты, медальон `r_<id>`);
- **награды за задания** — `TASK_REWARDS`, `EARLY_FACTOR` в `core/learning/lesson.js`;
- **темп обучения по умолчанию** — `DEFAULT_SETTINGS`, `APPETITES`, `LEARN_DELAY` в `core/learning/srs.js`;
- **встроенные слова** — `content/ru/words.js`; если меняется перевод или слово переезжает в другую встроенную колоду —
  поднять `WORD_DECKS_VERSION` (прогресс переносится по греческому слову, в том числе между колодами);
- **статья справки** — `PEDIA_ARTICLES` в `content/ru/pedia.js` (`part: 'study'` — в части «Учёба»); расчёт для неё —
  в `core/city/facts.js` (числа и id), текст — в `pedia.js`. Числа в текстах берите из данных (`${BALANCE…}`, `Game.…`),
  а не пишите руками — иначе они разойдутся с игрой;
- **новый файл** — одной строкой в `ASSETS` (`index.html`), на своё место по слоям.

После изменения механики **всегда обновляйте Кипропедию** — она должна описывать текущие правила —
и запускайте `npm run audit:pedia` (справка против ядра во всех эпохах) и, если менялись цены, `npm run prices`.

## 3. Состояние и сохранение

- Два мира — два сохранения в `localStorage`:
  - город — `Game.state`, ключ `greekgame.city.v1`: `epoch, res, logos, logosEarned, pop, techs, techPath, buildings, nextId, buffs, cooldowns, stash, timers, stats.goats, log, finished`;
  - обучение — `Learn.state`, ключ `greekgame.learn.v1`: `decks, progress, settings, learnLog, stats.{right, wrong, rounds, learned}`.
- Сохраняется раз в 5 секунд, при уходе со страницы и после важных действий (`Session.saveAll()`).
- **Вторая вкладка.** Рядом с каждым сохранением лежит штамп `<ключ>.stamp` — какая вкладка писала последней. Вкладка пишет, только пока штамп её; если поверх записала другая (ушла вперёд, начала новую игру, стёрла всё), эта останавливается и больше ничего не сохраняет — окно «Игра открыта в другой вкладке» с кнопкой «Загрузить свежую игру». Проверка — при каждой записи, при возвращении на вкладку и по событию `storage`. Раньше забытая старая вкладка при закрытии браузера или возвращении на неё записывала свою игру поверх новой.
- Старое общее сохранение (`greekgame.save.v2`) при первом запуске делится на два, а оригинал остаётся копией `greekgame.save.v2.bak`.
- Прогресс карточки `progress[cardId]`: `step` (шаги заучивания), `rev` (−1 — учится, ≥0 — индекс интервала выученного),
  `due` (когда снова пора), `right/wrong`, `built` (слово уже набирали), `back` (куда вернуться после забывания).
- **Три сброса** (решение: обучение ценнее города и не должно пропадать случайно):
  - «Новая игра» (`Game.newGame`) — город с нуля; обучение лежит отдельно и не трогается;
  - «Сбросить обучение» (`Decks.resetLearning`) — слова снова новые, город не трогается;
  - «Стереть всё» (`Session.wipe`) — как при первом запуске.
- Флаги `Game.resetting` / `Learn.resetting` не дают пересохранить старое во время сброса.
- Копия обучения — JSON `{ type: 'logos-learning', v: 1, decks, progress, settings, learnLog, stats }`.

## 5. Механика города

### Цены и производство
- Выпуск здания = база × **множитель уровня** (каждый уровень умножает: ×1.15 за ресурсы, ×1.25 / ×1.4 за Логос) × (1 + сумма постоянных бонусов знаний и чудес) × (1 + сумма благословений): благословения на один ресурс складываются (два ×2 = ×3).
- Постройка: каждое следующее здание того же типа дороже в **1.25** раза. Чудеса — по одному, цена фиксированная.
- Улучшение до уровня t = цена постройки × **1.5^(t−1)** ресурсами; с 4-го уровня добавляются товары (15 × 1.5^(t−4); после «Финикийцев» — серебро 5 : 1), с 6-го — медь, на 8-м — бронза, с 10-го — железо.
- **Уровни за Логос 3, 5, 7, 9 — только λ** (`BALANCE.wisdomLevels`): 3-й и 7-й — малые (3 и 9 λ, выпуск ×1.25), 5-й и 9-й — большие (`lp` и `lp × 3`, выпуск ×1.4). Уровни за ресурсы 2, 4, 6, 8 — ×1.15.
  Для игрока: «уровни за ресурсы» и «уровни за Логос», без слов «труд/мудрость/символический». В Кипропедии и в окне здания — «рост к прошлому уровню» (×1.15 / ×1.25 / ×1.4), облик по уровням не показываем — сюрприз. Предел уровня: 5 в медно-каменном веке, 9 в бронзовом (9-й — венец: «всё лучшее»). 1 раунд ≈ 55 λ — ориентир для всех λ-цен.
- Работники: базовое число здания + 1 за каждые 2 уровня. Места в жилище: round(4 × множитель уровня) + бонусы.
- **Нехватка рук:** сначала руки получают поля и загоны (здания, дающие зерно без сырья) — зерно работает на 100%;
  остальные делят оставшихся. Только если людей не хватает даже на поля, слабеет и зерно.
- **Переработчики** (гавань, литейня) не тратят сырьё на то, что не помещается: все выходы полны — здание отдыхает,
  часть полна — сырья уходит пропорционально меньше (у гавани: одно из двух полно — меди вдвое меньше).
- Склады: общий предел на каждый ресурс, 300 без построек + Склад (400 × множитель уровня) + бонусы.
  **Цена больше вместимости недоступна вовсе.**
- Каждый житель ест 0.05 зерна/с; рост — 1 житель за 6 с при свободных местах и зерне > 5; при голоде люди уходят.

### «Хозяйство в цифрах» (Кипропедия)
Живая страница «📊 Хозяйство в цифрах» (`a:income`) — три расчёта по городу игрока.
**Доход по ресурсам:** по каждому ресурсу — строки «здание · уровень × сколько»
с расчётом `база × уровень × (1 + бонусы) × (1 + благословения) × занятость`, сырьё переработчиков, еда жителей,
простаивающие/отдыхающие здания, источники бонусов и что дал бы «Сбор припасов». Данные — `Game.incomeBreakdown()`:
тот же цикл `Game.production()`, что и в такте (с журналом вкладов), поэтому сумма строк всегда равна доходу в шапке.
**Логос за карточки:** цена задания × множитель, из чего сложен множитель (`Game.logosBreakdown()`), когда снова доступны λ-благословения,
сколько сейчас даёт каждое задание и раунд. **Склады:** (база + склады + прибавки) × (1 + проценты) — `Game.storageBreakdown()`.

### Ценник ресурсов (мерка для баланса)
Сколько секунд работы одного жителя стоит единица ресурса (1-й уровень, без бонусов), в пересчёте на зерно:

| Зерно | Дерево | Камень | Сыр | Товары | Медь | Бронза | Железо | Серебро | Амфоры |
|---|---|---|---|---|---|---|---|---|---|
| 1 | 1.4 | 2 | ~1 (редок: только загоны) | 5 | 5 | ~29 | ~24 | 25 (= 5 товаров) | ~3.3 |

Считается из `BUILDINGS`: поле 2 работника → 0.5 зерна/с (4 с труда за зерно), каменоломня 2 → 0.25 камня/с (8 с) и т. д.;
сыр — остаток загона после зерна, бронза — труд литейни плюс медь. Переработчики выходят «в ноль»: гавань
(3 работника + 0.12 меди → 0.2 товаров + 0.35 зерна), литейня. Лишнее зерно на практике стоит меньше — его в основном съедают.
По этому ценнику сверяются обряды (ценность на 1 λ), а дальше — знания, переходы и будущий бот.

### Два пути к знаниям
У каждого знания два именованных пути (`paths`): 🧠 «с умом» — λ и немного ресурсов; 💪 «через силу» — без λ,
ресурсы ×3 плюс каждый λ цены заменяется 8 ресурсами (в медно-каменном веке дерево/камень пополам, в бронзовом — камень 40%, дерево 40%, товары 20%).
У знаний второй половины железного века (`buy: true`) путь «через силу» — **купить у чужеземцев**: каждый λ заменяется
`BALANCE.laborSilverPerLogos` = 0.75 серебра (по ценнику столько же, сколько 8 ресурсов). Названия путей это и говорят:
«Врач-чужеземец», «Кузнецы из Тира», «Корабли из Сидона».
С каждой эпохой путь «через силу» жёстче: вся его цена умножается на `BALANCE.laborEpochMult[эпоха]` (медно-каменный и бронзовый ×1,
железный ×1.5; следующие эпохи — ещё больше).

### Чудеса древнего Кипра
По мотивам реальных памятников (Лемба, Троодос, Суской, Хала-Султан-Текке, Энкоми, Аласия…). У каждого **одна цена**:
либо λ + скромные ресурсы, либо много ресурсов без λ. Чудо можно **убрать на склад** и бесплатно поставить в другое место;
на складе его бонус не действует, но для перехода эпохи оно засчитывается.
**Чудеса эпохи** (`retire` в `BUILDINGS`): Лемба и Мастера Суской при переходе в бронзовый век становятся домом и мастерской 5-го уровня
(`Game.retireWonders`, запись летописи `retired`, строка в окне новой эпохи). Об этом предупреждают карточка чуда, его окно, Кипропедия и вкладка «Эпоха».
Чудо со склада в новой эпохе ставится уже таким зданием. Бывшее чудо не поднимает цену следующего дома/мастерской. Святилище богини и Троодос не устаревают.
В железном веке так же уходят чудеса бронзового: Хала-Султан-Текке становится гаванью, Святилище Слиткового бога — бронзолитейней, обе 9-го уровня
(литейню потом, после «Железа», можно перестроить в кузницу 9-го уровня или продать).

### Обряды
- «Сбор припасов» — мгновенно 3 минуты обычного производства (без благословений, `Game.plainRates`) за 8 λ, раз в 2 минуты (стоит отдельно, сверху вкладки).
- Благословения — множители на время; продлеваются до 30 минут; **одновременно не больше 5**.
  Благословения длятся 10–20 минут («Всей семьёй» — 30), λ-благословения святилищ — 15 минут, под учёбу. «Всей семьёй» удваивает рабочие руки. Обряды прошлой эпохи в новой стоят ×1.5 λ.
- Благословения на один ресурс складываются (Урожай + Праздник = зерно ×3) и умножают постоянные бонусы.

| Обряд | λ (в бронзе) | Действует |
|---|---|---|
| Сбор припасов | 8 (12) | сразу 3 мин выпуска всего, раз в 2 мин |
| Всей семьёй | 15 (23) | руки ×2, 30 мин |
| Обряд урожая | 12 (18) | зерно ×2, 10 мин |
| Обряд труда | 12 (18) | дерево и камень ×2, 10 мин |
| Благословение стад | 5 (8) | загоны ×2, 10 мин + коза |
| Праздник плодородия | 40 (60) | всё ×2, 20 мин, рост ×3 |
| Наблюдение за звёздами | — | λ +50%, 15 мин, **раз в 4 часа** (сыр, товары, зерно) |
| Обряд рудокопов | 15 | медь и бронза ×2, 10 мин |
| Обряд торговли | 25 | гавани и литейни ×2, 20 мин |
| Толкование знамений | — | λ +75%, 15 мин, **раз в 8 часов** (медь, товары, сыр) |

По ценнику ресурсов благословения дают на 1 λ в 1.2–1.6 раза больше «Сбора припасов»; Стада и Рудокопы — ситуативные (зависят от числа загонов и рудников).

### События
- Беглые козы: появляются раз в 1–2 минуты на 14 секунд; поимка даёт либо 4 минуты производства одного ресурса,
  либо 1 минуту всех (с минимумами).
- Набеги «народов моря» в бронзовом веке: через случайные 5–30 минут игры (`BALANCE.raidEvery`), срок виден заранее — красная плашка
  с обратным отсчётом справа в полосе над картой (`Game.raidIn()`), после каждого набега новый срок. Уносят случайно 10–50% всех запасов
  (`BALANCE.raidLoot`), λ не трогают. Пока игрока нет, отсчёт идёт; если срок подошёл — набег ровно один, в конце офлайна
  (после прибавки), затем отсчёт с начала (новый `nextRaidIn()`). Циклопические стены отражают набег (без трофеев)
  и дают +50% к складам.
- **Дань** в железном веке (`Game.raidKind() === 'tribute'`): тот же таймер, «народы моря» в неё «превращаются».
  Кто и как берёт — `Game.overlord()` (по знаниям):
  - 🏹 **Ассирия** (с начала эпохи) грабит: те же 10–50% всех запасов, стены — вдвое (`halved`).
  - ☥ **Египет** (после «Дани фараону») берёт серебром столько, сколько в среднем унесли бы ассирийцы: 30% ценности остальных запасов
    по ценнику (со стенами 15%), без случайности (`Game.tributeDue()`, сумма на плашке и растёт вместе с запасами).
    Не хватает — забирают всё серебро, недостающую долю добирают грабежом (10–50% × доля недоплаты, стены — вдвое).
  - 👑 **Персия** (после «Даров царю царей») — твёрдая подать: при изучении знания (`fixTribute`) сумма считается один раз
    (`state.tributeFixed` = `BALANCE.tribute.persia` = 4 с жителя) и дальше не растёт. Недоимку берут ровно по ценнику (`BALANCE.worth`) одной долей из всех запасов.
  - «Флот царей» −25% к дани Египту и Персии (`effect.tributeCut`). Плашка спокойная, когда серебра на дань хватает.
  Итог `Game.raid()`: `{ lord, due, paid, short, lost, pct, halved }`; текст — `Msg.tributeLine` (всплывашка, летопись, «С возвращением!»).
  Тяжесть: Египет ≈ средний ассирийский грабёж, только серебром (остальные запасы целы); Персия — мягче: в городе на ~170 жителей
  со складами на 26k и запасами в 20–35% Египет просит 1200–2000 серебра (со стенами), Персия — около 670 и дальше не растёт.

### Железный век («Царства-города»)
Идея эпохи: **серебро — деньги царей, железо — их сила**. Цари Кипра живут между империями и откупаются серебром.
- Предел уровня **11** (`EPOCHS[2].maxLevel`). Переход: 150 жителей, Царские гробницы Саламина, все 9 знаний, 400 λ,
  серебро 2500, железо 1500, камень 10000. Следующая эпоха пока закрыта — переход заканчивает игру (`finished`).
  Старые сохранения, где бронзовый век был «концом прототипа» (`finished`), при загрузке снова открываются.
- **10-й уровень** — за ресурсы, ×1.15, и вместо бронзы просит **железо** (`BALANCE.ironFromLevel`). **11-й** — за Логос, ×1.4,
  цена `6 × lp` — вдвое дороже 9-го (`wisdomLevels[11]`).
- **Склады** на 10-м и 11-м растут резче: ×1.3 и ×1.6 вместо ×1.15 и ×1.4 (`BALANCE.storeGrowth`, `Game.storeMult`).
- **Перемены** (`retire` у знания в `TECHS`, код — `core/city/changes.js`):
  - `retire.res: { старый: { into, rate, stock, prodToo } }` — при изучении запасы переходят в новый ресурс по курсу `stock`
    (по умолчанию = `rate`; `stock: 0` — запасы просто пропадают, как бронза) (`applyRetire`,
    запись `resRetired`); все цены со старым ресурсом пересчитываются (`Game.liveCost` в ценах построек, улучшений, знаний,
    обрядов и перехода); бонусы к старому ресурсу переходят на новый (`Game.liveKey` в `effects`); старый ресурс пропадает из шапки.
    `prodToo` — здания продолжают работать, выпуская новый ресурс по курсу (для ремёсел → серебро); без него выход старого ресурса
    просто пропадает, и переработчик без выхода встаёт целиком, не тратя сырья и не занимая работников.
  - `retire.buildings: { старое: новое | { местность: новое } }` — тип устаревает: новые не строятся, в окне здания —
    «Перестроить» (тот же уровень, цена — базовая постройка нового; запись `rebuilt`) или «Продать» (весь λ его уровней за Логос
    + половина базовой цены; запись `sold`). Статья Кипропедии `a:changes`.
- **Улучшение чуда** (`upgradeOf` в `BUILDINGS`, `Game.upgradeWonder`): новое чудо встаёт на место старого (в городе или на складе),
  старое больше не строится (`Game.upgradedFrom`), обряды со старым `req` работают и при улучшенном (`Game.hasWonder`).
  Святилище богини → Святилище Афродиты Пафосской, Святилище Рогатого бога → Святилище Аполлона Гилата,
  Пастушьи тропы Троодоса → Виноградные склоны Троодоса (после «Виноградарства»). Кнопка «Улучшить» — во вкладке «Строить» и в окне чуда.
- **Обряды меняются**: `until` (уходит, когда святилище улучшено), `untilTech` / `tech` (уходит / появляется со знанием);
  обряд чуда прошлой эпохи прячется. «Наблюдение за звёздами» → «Таблицы Утренней звезды» (+100%, раз в 8 ч),
  «Толкование знамений» → «Гномон и полос» (+75%, раз в 4 ч), «Благословение стад» → «Праздник сбора винограда».
  Подношения новых обрядов заданы в старых ресурсах и пересчитываются сами (`liveCost`).
- **Торговая линия** (`trade` у здания, `Game.tradeOf`): работает той же рабочей силой и только если есть сырьё — основная работа
  от неё не зависит. Гавань после «Виноградарства» продаёт амфоры за серебро сверх обычного — только то, что сверх половины склада (`trade.keep: 0.5`): до этого амфоры копятся; лесорубы и каменоломни после
  «Железных топоров и кирок» тратят железо (0.005/с на 1-м уровне) и дают +30% дерева и камня. Подсказка у фишки — `tradeNote` в словаре.
- Устаревшие здания на карте серые со значком 🔄, работников не держат, не улучшаются.
- **Цены железного века сверены с бронзовым** по ценнику труда (`npm run prices`, `tools/balance/prices.js`). Сверяются только зоны
  утяжеления — знания, чудеса, переход; цель — до ~×3 по номинальным ресурсам, по-настоящему ~×2:

  | | Бронзовый век | Железный век | × |
  |---|---|---|---|
  | Знание «с умом», ресурсы | 2.5k на знание, 17.2k за эпоху (7 знаний, λ 1070) | 5.8k на знание, 52.6k за эпоху (9 знаний, λ 2280) | ~2.3 на знание, ~3.1 на эпоху |
  | Знание «через силу» | 72k за эпоху, 51 ед. ценника за 1 λ | 302k за эпоху, 109 за 1 λ (`laborEpochMult` ×1.5) | гораздо жёстче |
  | Чудеса, ресурсы | 37k (5 чудес) | 99k: Афродита 9k, Аполлон 50k, Троодос 14k, гробницы 9k, ваза 18k | ~2.7 |
  | Переход | 48k + 250 λ | 119k + 400 λ (серебро 2500, железо 1500, камень 10000) | ~2.5 |

  Здания в сверку не входят — они идут по общим правилам (10-й уровень против 6-го + 8-го выходит ×1.6–1.8; 30 железа;
  самый дорогой — гавань, 13.5k дерева).
- **Чудеса железного века** — «ум или сила»: за λ — Святилище Афродиты (600 λ, после «Финикийцев») и новое **Царские гробницы Саламина**
  (650 λ, после «Железа»; обязательно для перехода); без λ, но очень дорого — Святилище Аполлона (12000 камня, 2000 меди, 650 железа;
  после «Слогового письма»), Виноградные склоны Троодоса (8000 зерна, 4000 дерева; после «Виноградарства») и новая
  **Каменная ваза Амафунта** (5000 камня, 200 железа, 120 серебра; после «Железных топоров и кирок»; склады +25%).
  λ-бонус старого святилища сохраняется: Афродита +10% (как богиня), Аполлон +20% (как Рогатый бог).
  Часть цен первой половины перенесена на серебро и железо без изменения итога по ценнику: Афродита — 1000 товаров (= 200 серебра)
  вместо части камня, Аполлон — половина меди железом, гробницы — 120 железа (12 железных вертелов из гробницы 79),
  «золотые часы» святилищ — подношения больше серебром.
- **«Кипрское слоговое письмо»** λ не даёт: открывает писцам 10-й и 11-й уровни (`levelTech` у здания) и Святилище Аполлона.
- Знание **«Железо»**: бронза уходит совсем — запасы пропадают (`stock: 0`), цены с бронзой пересчитываются в железо 1 : 1;
  бронзолитейня → кузница (дерево → железо). Кузница пока нарисована как литейня.
- **«Финикийцы в Китионе»**: товары → серебро 5 : 1 (`prodToo`: мастерские и гавани сразу дают серебро), серебро +50%.
- **«Виноградарство и оливы»** (после финикийцев): сыр → амфоры 2 : 1; козьи загоны устаревают → виноградник (холмы) или
  оливковая роща (лес); вместо беглых коз — вакханки (`Game.goat.kind === 'maenad'`, если выпал один ресурс — это амфоры).
- **Вторая половина** — пять знаний, все с путём «купить у чужеземцев» (`buy`):
  - **«Дань фараону»** (после «Финикийцев»): Египет вместо Ассирии. Пути: «Договор с фараоном» / «Подарки вельможам Саиса».
  - **«Железные топоры и кирки»** (после «Железа» и «Финикийцев»): торговая линия у лесорубов и каменоломен; открывает вазу Амафунта.
    Пути: «Закалка в воде» / «Кузнецы из Тира».
  - **«Врачи Идалиона»**: +2 места в жилище, рост +50%. Пути: «Своя школа врачей» / «Врач-чужеземец».
  - **«Флот царей»** (после «Дани фараону»): только −25% дани, гавани не трогает. Пути: «Свои верфи» / «Корабли из Сидона».
  - **«Дары царю царей»** (последнее): Персия, твёрдая подать. Пути: «Опись городов» / «Дары к трону».
- **Источники** — статья Кипропедии `a:sources`: выписки и ссылки (призма Асархаддона, Геродот II 182, III 19/89/91/131, VII 90,
  Идалионская табличка, гробница 79 в Саламине, ваза Амафунта, Тамас и «Темеса»). Новые находки — туда же.

### Офлайн
Игра «спит» во вкладке в фоне. При возвращении (`Game.catchUp`): считается настоящее время отсутствия, максимум 8 часов.
Выпуск и рост — первые 5 минут в полную силу, дальше вполовину; благословения и перерывы обрядов истекают по настоящему времени
(`Game.passTime`). Затем, если срок подошёл, — один набег по накопленному. Окно «С возвращением!» показывает прибавку,
жителей, закончившиеся благословения и потери от набега.

### Переход эпохи
Население, обязательные чудеса, все знания эпохи, запасы и немного λ (120 в бронзовый век, 250 — в следующий). Рассчитан на несколько дней.
Это единственное исключение из правила «одна тяжёлая часть цены».

**Логос по ходу эпохи — равномерно.** Крупные траты λ не должны копиться к концу:
- начало — первые знания и большое чудо без поздних ресурсов (Лемба; в бронзовом веке — Дворец Аласии);
- середина — обязательное святилище (богини плодородия — камень и товары; Рогатого бога — камень, медь и товары, без бронзы);
- конец — последнее знание эпохи («Первая медь» после «Красно-белой керамики»; «Бронзовые орудия») и высокие уровни зданий;
- переход — немного λ, главное — запасы и население.

**Ориентир по Логосу.** 1 раунд из 8 карточек ≈ 55 λ до бонусов (`ROUND_LAMBDA`). Медно-каменный век — около 10 раундов, бронзовый — ещё около 15.
Постоянный множитель λ: святилище богини +10%, писцы +8–26%, Святилище Рогатого бога +20%. λ-благословения — «золотые часы»:
«Наблюдение за звёздами» +50% на 15 минут раз в 4 часа, «Толкование знамений» +75% на 15 минут раз в 8 часов. Перерыв идёт
по настоящим часам (`realTime`, `state.readyAt`), а не по игровому времени, — поэтому переживает уход из игры.

## 6. Обучение

### Раунд
- По умолчанию 8 карточек: сначала заучиваемые, потом те, что пора повторить, потом до 5 новых, потом досрочные.
- Новое слово: знакомство, а в конце того же раунда — проверка.
- Задания: «Что это значит?» (греч. → перевод), «Как это по-гречески?», «Соедините пары» (4 пары), «Вспомните сами»,
  **«Какая буква?»** (пропуск в трудном месте: ι/η/υ/ει/οι, ο/ω, ε/αι) и **«Соберите слово»**
  (короткое — из букв, длинное — из слогов, не больше 6 кусков, + 2–3 обманки, похожие на слух; можно печатать с клавиатуры).
- Варианты ответа берутся из той же колоды (та же часть речи).

### Встроенные колоды и уровни
- Id колоды начинается с уровня: `a1-…`, `a2-…`, `b1-…` (`Decks.levelOf`); в «📚 Обучении» колоды сгруппированы по уровням,
  уровень можно включить целиком. Колоды A2 и B1 приходят выключенными (`"off": true`), A1 — включёнными.
- Источник — учебник «Κλικ στα ελληνικά» (A1/A2/B1). **Правило уровня — гибридное:** основа — уровень из учебника,
  поправка — частотность (zipf): слово из B1 учебника, которое по частотности A1/A2, считается A2. Из этого пула слова
  отбираются вручную: учебниковые «базовые» слова, ошибки разбора (ударения, опечатки, части речи) и редкая лексика отсеиваются.
- **«Что будем учить?»** — вопрос в начале каждой новой игры (после вступления; если игрок закрыл окно — перед первым раундом,
  флаг `planPending` в состоянии города). Ответ — **подборка колод**: `LEARN_PLANS` в `core/learning/decks.js`
  (`a1start` — «A1 · начинающий», `a1` — «A1+», весь A1, `a2`, `b1`, `verbs` — глаголы A1–B1, `own` — если есть свои колоды);
  подборка задаётся списком id колод (`decks`) или целыми группами (`groups`), тексты — `Lex.plan`.
  Подборка включает свои колоды и выключает остальные, прогресс не трогает. Если игрок уже учился, есть «Оставить как сейчас».
  Сменить — «📚 Обучение» → «Обзор» → «Сменить».
- Каждое греческое слово встречается во встроенных колодах A1–B1 **один раз** (кроме стартового набора); это проверяет тест.
  Варианты одного глагола (`συζητώ` / `συζητάω`) — тоже одно слово.
- Колоды по грамматике, по 16–45 слов (глаголы A1 — до 70): связки и наречия; существительные ο / η / το; люди и профессии; прилагательные;
  глаголы на -ω; глаголы на -άω/-ώ и -μαι; в A2 — «Язык учебника» (термины грамматики и слова из заданий,
  переехали туда из A1). Колоду «Фразы для письма» убрали — фразы слишком длинные для заданий;
  встроенная колода, которой больше нет в `words.js`, удаляется из сохранения вместе со своим прогрессом.
- Подсказки: у существительных — артикль, у среднего рода на -μα/-ος — и множественное число; у прилагательных — окончания;
  у глаголов A2/B1 — аорист (или управление: «ενδιαφέρομαι για…»).
- Перевод — свой, ручной (английский столбец учебного списка — только ориентир, машинный русский не используется).
  Переводы внутри уровня не повторяются, чтобы в «Что это значит?» не было двух верных вариантов.
- В версии 3 (`WORD_DECKS_VERSION = 3`) 36 слов переехали из A1 в A2/B1; прогресс по ним сохранён. Если переехавшее слово
  попало в выключенную колоду, оно не повторяется, пока игрок её не включит, но остаётся выученным.
- **Версия 4** — по 100 новых слов в A1, A2 и B1:
  - A1: колоды «Существительные ср. р. (το)», «Прилагательные», «Связки и наречия времени» и числа/наречия места в «Числа и наречия места»
    (`a1-adv`). Это самое базовое, чего в A1 не было: παιδί, όνομα, καλός, μεγάλος, αλλά, όταν, τώρα, δύο… Несколько слов
    уровня A2 по учебнику, но A1 по частотности (καλός, παλιός, ζεστός, έξω, καλά), отнесены к A1.
  - A2: «Наречия» (на -α), вторые колоды ж. и ср. рода, пополнены м. р., люди, прилагательные и глаголы.
  - B1: «Люди и профессии», вторые колоды ж. и ср. рода, пополнены м. р., прилагательные, глаголы и связки.
  - Большие колоды A1 поделены пополам по алфавиту (`a1-masc` / `a1-masc2`, `a1-fem` / `a1-fem2`); прогресс идёт за словом.
    Если встроенная колода исчезнет совсем, прогресс её слов тоже переходит к тому же слову в другой встроенной колоде.
  - Подборка «A1 · начинающий» теперь включает и связки, и прилагательные.
  - Как пополнять колоды — `tools/README.md`: пулы по частотности (`tools/words/pools.py`), рукописный список с переводами
    (`tools/words/additions_v4.py` — образец и запись версии 4) и `tools/words/apply_decks.py` с проверками.

### Как слово становится выученным
- Шагов до «выучено» **ровно столько, сколько выбрано в настройках** (2–5). Ученика не нагружаем сверх выбранного темпа.
- **Последний шаг — всегда набор слова.** «Какая буква?» может попасться на любом шаге и считается шагом.
- Ошибка в переводе — шаг назад. **Ошибка в написании («Какая буква?», набор) шаг не откатывает**:
  перевод и написание — разные знания; слово просто ещё раз пойдёт на набор. Выученному слову после такой ошибки хватает одного верного набора.
- Выученное повторяется по «аппетиту»: редко / умеренно / часто (`APPETITES`).
- Ошибка набора: в наборе зелёное — верно, красное — неверно, оранжевое — не то ударение; в правильном слове выделено место ошибки.
  Никаких «вторых попыток» — неправильно значит неправильно.

### Награды
- λ зависит **только от типа задания**: набор 12, «Как по-гречески?» 7, «Какая буква?» 6, «Что это значит?» 6, пара 3, «Вспомните сами» 1;
  досрочное повторение ×0.4; знакомство — 0. **Серии верных ответов не поощряются.**
- Цель калибровки: **≈ 55 λ за раунд** (`ROUND_LAMBDA`) до бонусов святилищ и писцов. Цена задания видна в вопросе.

### Экран «📚 Обучение»
Отдельный, «спрятанный» экран (кнопка 📚 рядом с 📖 и ссылка в конце раунда): обзор и журнал по дням, колоды, таблица слов
с фильтрами, темп и награды, импорт/экспорт, сбросы. Кнопка «📜 Учиться» в шапке — без подписей; что будет в раунде («пора повторить 3, новых до 5») — в её подсказке, а когда нечего повторять и учить, она не мерцает.

## 7. Интерфейс

- **Шапка:** эпоха → медальон λ (на почётном месте, под числом — бонус к Логосу) → ресурсы (число, прирост, полоска заполнения склада)
  → жители и работники → 📖 → 📚 → «Учиться» (без подписей под ней). Размер склада отдельной плашкой не показывается — он в подсказке и в полоске.
  **Прирост виден всегда.** Ресурсы не помещаются — ячейки становятся плотнее (`UI.fitRes`, `data-fit` 1–3: мельче → значок над числом →
  ещё мельче, на 3-й ленту можно прокрутить); обратно к крупным — только при смене ширины окна или числа ресурсов, чтобы шапка не дёргалась.
- **Красный = требует внимания:** ресурс тает (ячейка розовеет, ▼), склад полон, не хватает рук (красная мигающая плашка).
  Золотая подсветка — ресурс под благословением.
- **Полоса благословений** над картой: место под неё есть всегда (5 пустых кружков), никогда не переносится на вторую строку —
  если тесно, названия прячутся, остаются значки и таймеры.
- Вкладки: «Строить» (обычные здания, ниже чудеса), «Знания» (сначала доступное сейчас, изученное и прошлые эпохи — свёрнуты),
  «Обряды» («Сбор припасов» сверху), «Эпоха» (переход, хронология, летопись, «Новая игра»).
- Слои поверх: окно (z 900) > раунд карточек (800) > Кипропедия (700) > «Обучение» (650).
- Клавиши: F1/? — справка, Esc — закрыть/отменить, Shift+клик по зданию — улучшить, U в окне здания — улучшить,
  в раунде 1–4 / Enter / Пробел / Backspace.
- На телефоне — честное предупреждение, что игра сделана под компьютер.
- **Телефон** — пока внутри интерфейса ПК: та же разметка и `UI`, раскладка — `ui/desktop/phone.css`
  (`@media (orientation: landscape) and (max-height: 520px)`), сенсорное управление — `ui/desktop/phone.js`. Правил игры там нет.
  Принципы телефона:
  - **Только альбомная ориентация и полный экран.** В портретной — просьба повернуть; без полного экрана — заслонка
    «Играть на весь экран» (браузер даёт полный экран только по нажатию). На iPhone полного экрана из браузера нет —
    подсказка «Поделиться → На экран „Домой“» в предупреждении, а `manifest.webmanifest` открывает игру с главного экрана без панелей.
  - **Окна и панели — на весь экран**, если место не очевидно свободно: окно здания (двумя колонками), эпоха, план, раунд,
    Кипропедия, «Обучение», вкладки. Маленькие окна (подтверждение) — маленькие. Закрыть — **✕** в углу; кнопки окна
    прилипают к низу. Выдвижная панель подписана, откуда она («🔨 Строить»), карточки в ней — сеткой.
  - **Карта — на всю ширину**, а север и юг, что не влезли по высоте, листаются пальцем (`#mapScroll`); тень с ▲ / ▼ у края — там ещё есть
    карта; при запуске в середине экрана — город. Благословения и срок набега — узкой полосой слева от карты, не поверх клеток.
  - **Шапка:** ресурсы — ровно по содержимому (число и прирост), остальное место — жителям и «Учиться».
  - **Свернуть, а не уместить:** вступление эпохи — под катом, оглавление справки — по ☰, разделы «Обучения» — полоской значков,
    описания знаний и обрядов — в две строки (целиком — в справке по «?»).
  - **Значки вместо слов:** справка 📖 и учёба 📚 — в полосе справа (`#rail`), на низком экране подписи у неё пропадают;
    у путей знания — 🧠 / 💪 и название пути; клавиши (`kbd`) на кнопках не показываются.
  - **Подсказки — долгим нажатием:** всё, что на компьютере всплывает под мышью (`title`), показывает `#touchTip`; отпущенный палец
    после подсказки — не нажатие (не строит, не собирает, не открывает).
  - **Shift+клик → режим ⏫:** пока он включён, каждое касание здания — +1 уровень; на карте зелёная стрелка — ресурсов хватает,
    золотая λ — уровень за Логос, бледное — нельзя. «Shift при строительстве» → кнопка **🔁 ещё** на плашке «куда поставить».
    Касание карточки во вкладке «Строить» — то же, что кнопка «Строить».
  - Проверка: `npm run phone` (`tools/phone/check.js`) — снимки всех экранов и касания на эмуляторе телефона.

### Графика
- Иконки — рисованные SVG в поле 64×64, единая палитра и контур (`assets/art.js`). Эмодзи остаются только в тексте и журнале.
- Облик здания (`Looks.looks` / `Looks.icons` в `ui/common/looks.js`) зависит от **уровня**, а эпоха лишь добавляет свои верхние уровни —
  **каждая эпоха рисует только свои новые уровни**, нижние берут облик прошлых эпох (вместе с названием — `Looks.name`):
  | Здание | Медно-каменный век | Бронзовый век | Железный век |
  |---|---|---|---|
  | старое (медного века) | 1 `p0` · 3 `p1` · 5 `p1`+`p0` | 1, 3 — медные · 5 `p2` · 7 `p3` · 9 `p3`+`p2` | 1, 3 — медные · 5, 7 — бронзовые · 9 `p4` · 11 `p5`+`p4` |
  | бронзового века | — | 1 `p0` · 3 `p1` · 5 `p1`+`p0` · 7 `p2` · 9 `p2`+`p1` | 1–7 — как в бронзовом · 9 `p3` · 11 `p4`+`p3` |
  | железного века | — | — | 1 `p0` · 5 `p1` · 9 `p2` · 11 `p2`+`p1` |

  «`a`+`b`» — главный рисунок и рядом второй, поменьше. Облик меняется на 5-м уровне при переходе в бронзовый век
  (с лучшего медного на начальный бронзовый) и на 9-м — в железный. Нет рисунков новой эпохи (козий загон уходит
  с «Виноградарством», литейня — с «Железом») — остаётся лучший облик прошлой. Названия обликов — `forms` у здания
  (`Lex.bld[тип].forms[эпоха].name`): хижина 1-го уровня и в бронзовом веке зовётся «Круглая хижина».
- Железный век: тёсаный камень, протоэолийские колонны с завитками, серое железо, финикийский пурпур и серебро
  (дом с двором и портиком, поле с железным плугом и журавлём, верфь, царская каменоломня с капителью, керамика «свободного поля»
  и мастерская серебряных дел, склад амфор и царская кладовая, рудник со шлаковым отвалом, гавань с молом и корабельный сарай Китиона,
  царский архив, кузница: горн → навес → царская кузница).
- В Кипропедии рисунки обликов не показываем (сюрприз), только названия по уровням (строка «Облик»).
- **Облик с 4-го уровня должен отличаться заметно** (не «копеечка»): двор из двух хижин, двухэтажный дом, золотое поле, каменная овчарня…
  На карте здания 1–3 уровня рисуются мельче.
- Поля рисуются прямо на земле клетки, без тени и подставки.

## 8. Принципы и принятые решения

- **Ум или сила.** У любой цены одна тяжёлая часть: либо много λ и немного ресурсов, либо много ресурсов без λ.
  Ничто не стоит одновременно много λ и много ресурсов. Исключение — переход эпохи.
- **λ первичен, но не обязателен.** Тратить λ можно с первых минут (обряды), но без карточек игра тоже идёт.
- **Рост вверх, а не вширь.** Земля на острове ограничена, поэтому новые эпохи не наращивают сложность количеством:
  в шапке остаётся около 7 ресурсов, в эпохе — 4–5 чудес, новых обычных зданий почти нет. Город растёт **уровнями**
  (предел +2 за эпоху: 5 → 9 → 11 → …) и **превращениями**: старое здание становится новым, старый ресурс уходит,
  его место занимает новый. Чем дальше эпоха, тем больше в ней апгрейдов и меньше стройки.
- **Перемены — мягко и посреди эпохи.** Эпоха начинается с привычного хозяйства прошлой, а старое уходит по ходу —
  через знания, а не разом на границе. Уходящее не пропадает даром: здание можно **перестроить** в новое (уровень сохраняется)
  или **продать** (вложенный в его уровни Логос возвращается, часть ресурсов тоже); запасы уходящего ресурса
  переходят в новый по ценнику труда. Драгоценный λ при переменах не теряется.
- **Длина эпохи.** Каждая следующая эпоха длиннее прошлой — заметно, но без скачка в «сверхжёсткость»: ориентир — примерно
  в 1.5 раза дольше по настоящему Логосу (по раундам, с учётом выросшего множителя λ) и до ~×3 по номинальным ресурсам
  в зонах утяжеления — с уровнями и бонусами по-настоящему это около ×2.
  Склады должны поспевать за ценами переходов: в эпоху с новыми уровнями склады на этих уровнях растут резче.
- **Путь «через силу» с каждой эпохой жёстче** (`BALANCE.laborEpochMult`): чем дальше, тем выгоднее учиться, а не таскать камни.
- **Зоны утяжеления — чудеса, знания и переходы эпох.** Только их цены от эпохи к эпохе специально поднимаются.
  Здания дорожают лишь по общим правилам (×1.5 за уровень, товары / медь / бронза / железо с нужных уровней, λ на нечётных,
  ×1.25 за каждое следующее того же типа) — их цены отдельно не утяжеляются.
- **Улучшение чуда не отнимает.** Чудо, выросшее из старого, сохраняет его λ-бонус и добавляет своё.
- **Учёба не наказывает и не надоедает:** серии не поощряются, ошибки не «сжигают» прогресс, всё укладывается в выбранный темп.
- **Обучение живёт отдельно от города:** новая игра его не трогает.
- **Интерфейс без лишних слов:** в панелях — цифры и иконки; правила и рассказы — в Кипропедии. Каждая статья начинается с мини-истории.
- **Слова вместо сокращений:** «работников», а не «работн.».
- **Историческая правда:** названия и сюжеты — по реальной археологии Кипра; картинки-иллюстрации — ссылки на Wikimedia Commons.

## 9. Как работаем над проектом

- Делать **ровно то, что попросили**. Не придумывать дополнительные механики «от себя».
  Если просьбу можно понять по-разному — спросить или явно написать в отчёте, как поняли.
- Роадмапа и бэклог — **один общий список**; новые пункты записываются как есть, коротко.
- После изменений: `npm test`, при рефакторинге — «золотой эталон» до и после; поднять `ASSET_V` в `index.html`, обновить Кипропедию (`npm run audit:pedia`) и этот файл.
- Ядро не трогает страницу и не пишет русских фраз — только коды; новые тексты — в `content/ru/`.
- Отчёт после работы: по пунктам — **что проверить**, затем **весь оставшийся список**. Без диффов.
